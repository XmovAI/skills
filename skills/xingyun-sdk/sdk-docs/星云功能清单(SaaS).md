# 星云功能清单(SaaS)

| 分类 | 功能 | 说明 |
|-|-|-|
| 配置项 | SDK 构造选项 | 配置渲染容器、应用凭证、网关地址、布局与行走初始参数、GPU加速策略及调试开关等 |
|  | 会话配置 | 配置数字人的外观模型、骨骼模型形象、TTS音色、动画风格、背景图、音频格式及缓存策略等 |
| 会话管理 | 创建会话 | 向服务端发起请求，获取会话ID、WebSocket地址及数字人资源包信息 |
|  | 销毁会话 | 主动结束会话，释放服务端资源 |
|  | 初始化SDK | 下载数字人资源包，支持监听下载进度，可选择隐身模式启动 |
|  | 销毁SDK | 完整释放所有本地资源，断开连接 |
| 渲染控制 | 启动/暂停渲染 | 控制数字人画面的开始与暂停 |
|  | 隐身模式 | 暂停音视频渲染但保持连接不断开，适合后台切换场景 |
|  | 显示/隐藏 | 仅控制数字人画面的显示或隐藏，不影响渲染流 |
|  | 画面布局调整 | 调整数字人在容器中的对齐方式、缩放比例和偏移位置 |
|  | 跳转指定帧 | 跳转到动画的某一特定帧 |
| 语音与对话 | 发送文本/SSML驱动说话 | 输入文本或SSML标签，数字人用配置音色朗读并同步口型动作 |
|  | 流式分段发送 | 将长文本拆分为多个片段发送，降低首字延迟，支持动态追加内容 |
|  | 外部音频输入 | 跳过TTS环节，直接传入外部音频及音素时间戳，适合使用第三方语音的场景 |
|  | 音量控制 | 调节数字人播报音量大小 |
|  | 打断播报 | 立即停止当前播报，适用于用户插话或切换话题场景 |
| 状态管理 | 切换数字人状态 | 支持待机、聆听、思考、交互待机等状态切换，不同状态对应不同姿态和微动作 |
|  | 查询当前状态 | 获取数字人当前所处的状态 |
| 肢体动作 | 关键动作 | 通过动作名称触发预置动作（如挥手、鞠躬等） |
|  | 意图动作 | 按情绪或意图类别自动匹配并触发合适的动作 |
|  | 文本自动匹配动作 | 开启后，SDK根据文本语义自动插入匹配的关键动作 |
|  | 行走至指定位置 | 控制数字人在画面内左右移动到预设目标点 |
|  | 行走区域配置 | 配置数字人可移动的范围及目标点位置 |
| 字幕与UI | 自动生成字幕 | 数字人播报时，画面底部自动跟随显示字幕 |
|  | 字符级时间戳 | 开启后，可获取每个字符对应的时间戳信息，适用于逐字高亮等精细场景 |
|  | 自定义字幕 | 在数字人不说话时，主动在底部显示自定义文字内容 |
|  | 动态UI组件 | 支持在数字人周围动态叠加文字、图片、轮播图、视频、网页等组件，可指定位置和关闭 |
|  | UI组件事件回调 | 接收用户对UI组件的交互事件（如点击、播放完成等） |
| 事件与回调 | 状态变化回调 | 监听数字人的连接状态、渲染状态、动画状态、行走状态变化 |
|  | 语音播报回调 | 监听说话开始/结束、语音开始/结束事件，可关联业务自定义ID进行追踪 |
|  | 进度与网络回调 | 监听资源下载进度、网络质量信息（带宽、延迟） |
|  | 错误与警告回调 | 接收SDK运行时的错误和警告信息 |
|  | 后端事件流 | 通过WebSocket接收服务端推送的各种实时事件（说话开始/结束、字幕出现/消失、动作触发、行走事件等） |
| 网络容错 | 自动断网检测与离线切换 | 网络断开后，自动切换到本地循环动画，保持画面"活着"的状态 |
|  | 自动重连 | 网络恢复后自动重连，重连间隔逐渐增大，最多尝试27次 |
|  | 断线数据恢复 | 重连成功后，自动补回断开期间丢失的最近5秒动画数据 |
|  | 手动控制离线/在线 | 支持业务主动切换离线/在线模式；离线模式下不消耗积分，适合演示或弱网环境 |
| 调试工具 | 调试信息浮层 | 在画面上显示实时FPS、帧耗时、内存占用等性能数据 |
|  | 获取会话ID | 获取当前会话的ID，便于与后端日志关联排查问题 |
