# 2.3 事件与回调 — 完整回调接口说明

SDK 通过构造参数中的回调函数向外部传递各种事件。所有回调均为可选（`onMessage` 除外，强烈建议实现）。

## onMessage — 错误与事件通知

SDK 内部所有错误和重要事件都通过此回调上报。

```typescript
onMessage(error: SDKError) => void
```

**SDKError 结构**：

| 属性 | 类型 | 说明 |
|-|-|-|
| `code` | `EErrorCode` | 错误码 |
| `message` | `string` | 错误描述信息 |
| `timestamp` | `number` | 错误发生的时间戳 |
| `originalError` | `any` | 原始错误对象（可选） |

```javascript
const avatar = new XmovAvatar({
  // ...
  onMessage(error) {
    // 根据错误码分类处理
    if (error.code >= 10000 && error.code < 20000) {
      console.error('[初始化错误]', error.code, error.message);
    } else if (error.code >= 50000 && error.code < 60000) {
      console.warn('[网络错误]', error.code, error.message);
    } else {
      console.error('[SDK 错误]', error.code, error.message);
    }

    // 上报到你的监控系统
    reportToMonitoring({
      type: 'sdk_error',
      code: error.code,
      message: error.message,
    });
  },
});
```

## onStatusChange — 数字人状态变化

数字人整体状态发生变化时触发。

```typescript
onStatusChange(status: AvatarStatus) => void
```

**参数**：`AvatarStatus` 枚举值，为**数字类型**，对应关系如下：

| 值 | 状态 |
|----|------|
| 0 | 在线 |
| 1 | 离线 |
| 4 | 关闭 |
| 5 | 可见 |
| 6 | 隐身 |

```javascript
const avatar = new XmovAvatar({
  // ...
  onStatusChange(status) {
    switch (status) {
      case 0: // 在线
        console.log('数字人已上线');
        updateUI('connected');
        break;
      case 1: // 离线
        console.log('网络断开，正在重连...');
        updateUI('reconnecting');
        break;
      case 6: // 隐身
        console.log('进入隐身模式');
        updateUI('hidden');
        break;
      case 4: // 关闭
        console.log('会话已结束');
        updateUI('disconnected');
        break;
    }
  },
});
```

### 断线重连场景

当网络断开时，SDK 自动进入离线（`offline`，`status=1`）状态并播放预缓存的 Idle 动画，同时进行自动重连（最多 27 次）。重连成功后自动恢复到在线（`online`，`status=0`）/ 可见（`visible`，`status=5`）状态。

```
visible ──(断线)──► offline ──(重连成功)──► visible
                       │
                  (重连失败)
                       │
                       ▼
                    close
```

## onRenderChange — 渲染状态变化

渲染管线状态发生变化时触发。

```typescript
onRenderChange(state: RenderState) => void
```

**参数**：`RenderState` 枚举值（`'init'` | `'rendering'` | `'pausing'` | `'paused'` | `'resumed'` | `'stopped'`）。

```javascript
const avatar = new XmovAvatar({
  // ...
  onRenderChange(state) {
    console.log('渲染状态:', state);
  },
});
```

## 语音状态回调

### onVoiceStateChange

语音播放状态变化时触发。

```typescript
onVoiceStateChange(state: string, duration?: number) => void
```

| 参数 | 类型 | 说明 |
|-|-|-|
| `state` | `string` | `'start'` 表示语音开始播放；`'end'` 表示播放结束 |
| `duration` | `number` | 语音时长（毫秒），仅在 `'start'` 时提供 |

```javascript
const avatar = new XmovAvatar({
  // ...
  onVoiceStateChange(state, duration) {
    if (state === 'start') {
      console.log('语音开始播放');
      showSpeakingIndicator(true);
    } else if (state === 'end') {
      console.log(`语音播放结束，时长: ${duration}ms`);
      showSpeakingIndicator(false);
    }
  },
});
```

### onSpeakStateChange

说话状态变化时触发，与 `speak()` 方法的调用关联。

```typescript
onSpeakStateChange(state: string, client_speak_id: string | number) => void
```

| 参数 | 类型 | 说明 |
|-|-|-|
| `state` | `string` | `'speak_start'` = 开始说话；`'speak_end'` = 说话结束；`'speak_error'` = 说话出错 |
| `client_speak_id` | `string` | 本次说话的唯一标识，用于关联 `speak()` 调用 |

```javascript
const avatar = new XmovAvatar({
  // ...
  onSpeakStateChange(state, speakId) {
    switch (state) {
      case 'speak_start':
        console.log(`[${speakId}] 开始说话`);
        break;
      case 'speak_end':
        console.log(`[${speakId}] 说话结束`);
        // 说话结束后回到交互空闲状态
        avatar.interactiveidle();
        break;
      case 'speak_error':
        console.error(`[${speakId}] 说话出错`);
        break;
    }
  },
});
```

## onWalkStateChange — 行走状态

行走动画状态变化时触发。

```typescript
onWalkStateChange(state: string) => void
```

| 参数 | 类型 | 说明 |
|-|-|-|
| `state` | `string` | `'walk_start'` = 开始行走；`'walk_end'` = 停止行走 |

```javascript
const avatar = new XmovAvatar({
  // ...
  onWalkStateChange(state) {
    if (state === 'walk_start') {
      console.log('数字人开始行走');
    } else if (state === 'walk_end') {
      console.log('数字人停止行走');
    }
  },
});
```

## onWidgetEvent / proxyWidget — UI 组件事件

### onWidgetEvent

服务端推送 UI 组件事件时触发。所有类型的组件事件都会通过此回调传递。

```typescript
onWidgetEvent(data: IRawWidgetData) => void
```

```javascript
const avatar = new XmovAvatar({
  // ...
  onWidgetEvent(data) {
    console.log('组件事件:', data.type, data);
    // 根据组件类型处理
    switch (data.type) {
      case 'subtitle':
        updateSubtitle(data.content);
        break;
      case 'picture':
        showPicture(data.url);
        break;
    }
  },
});
```

### proxyWidget

按组件类型注册自定义渲染函数。注册后，该类型的组件事件**不会**走 SDK 内置渲染器，而是调用你注册的函数。

```typescript
proxyWidget: {
  [key: string]: (data: any) => void
}
```

```javascript
const avatar = new XmovAvatar({
  // ...
  proxyWidget: {
    // 自定义处理 'custom_card' 类型的组件
    'custom_card': (data) => {
      renderCustomCard(data);
    },
    // 自定义处理 'product_info' 类型的组件
    'product_info': (data) => {
      showProductInfo(data);
    },
  },
});
```

> **说明**：`proxyWidget` 中注册的类型，其事件不会传到 `onWidgetEvent` 回调。未注册类型的组件事件仍走 `onWidgetEvent`。

**事件优先级**：`onWidgetEvent` > `proxyWidget` > SDK 内置默认事件。

**SDK 内置事件类型**：

| 事件 type | 说明 | 数据字段 |
|-|-|-|
| `subtitle_on` | 显示字幕 | `data.text` |
| `subtitle_off` | 隐藏字幕 | — |
| `widget_pic` | 显示图片 | `data.url` |

**应用层自定义事件（通过 proxyWidget / onWidgetEvent 实现）**：

| 事件 type | 说明 |
|-|-|
| `show_image` | 展示图片卡片 |
| `show_video` | 播放视频 |
| `show_link` | 显示链接 |
| `show_text` | 展示文本卡片 |
| `bgm_start` | 播放背景音乐 |

> 自定义事件由服务端通过 SSML `<uievent>` 标签下发，客户端通过 `proxyWidget` 或 `onWidgetEvent` 接收并自行渲染 UI。

## onNetworkInfo — 网络质量监控

网络质量信息更新时触发，可用于展示网络状态或做自适应策略。

```typescript
onNetworkInfo(info: INetworkInfo) => void
```

**INetworkInfo 结构**：

| 属性 | 类型 | 说明 |
|-|-|-|
| `rtt` | `number` | 往返时延（毫秒） |
| `downlink` | `number` | 下行速率（Mbps） |
| `networkStatus` | `boolean` | 网络状态，`true` 为在线，`false` 为离线 |

```javascript
const avatar = new XmovAvatar({
  // ...
  onNetworkInfo(info) {
    console.log(`网络质量: RTT=${info.rtt}ms, 下行=${info.downlink}Mbps`);

    // 根据网络质量做自适应
    if (info.rtt > 500) {
      console.warn('网络延迟较高，可能影响体验');
    }
  },
});
```
