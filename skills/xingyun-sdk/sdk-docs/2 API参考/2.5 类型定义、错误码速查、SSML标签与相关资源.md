# 2.5 类型定义、错误码速查、SSML标签与相关资源

本章节定义了SDK涉及的全部类型、错误码、SSML标签及动作意图定义，方便快速查阅。

## 完整类型定义参考

### IAvatarOptions

```typescript
interface IAvatarOptions {
  // === 必填 ===
  appId: string;
  appSecret: string;
  gatewayServer: string;
  onMessage: (error: SDKError) => void;

  // === 容器配置（二选一）===
  containerId?: string;      // CSS 选择器，如 '#avatar-container'
  container?: HTMLElement;   // 容器 DOM 元素，优先级高于 containerId

  // === 可选配置 ===
  gateway_type?: string;     // 网关类型，默认 'default'
  config?: AvatarConfig;
  enableClientInterrupt?: boolean;

  // === 回调 ===
  onStatusChange?: (status: AvatarStatus) => void;
  onRenderChange?: (state: RenderState) => void;
  onVoiceStateChange?: (state: string, duration?: number) => void;
  onSpeakStateChange?: (state: string, client_speak_id: string | number) => void;
  onWalkStateChange?: (state: string) => void;
  onWidgetEvent?: (data: IRawWidgetData) => void;
  onAAFrameHandle?: (data: any) => void;
  onNetworkInfo?: (info: INetworkInfo) => void;
  onStartSessionWarning?: (message: object) => void;
  onStateRenderChange?: (state: string, duration: number) => void;
  onFPSUpdate?: (stats: any) => void;
  proxyWidget?: Record<string, (data: any) => void>;
}
```

### IInitParams

```typescript
interface IInitParams {
  onDownloadProgress: (progress: number) => void;  // 必填，资源加载进度回调
  initModel?: InitModel;                            // 初始化模式（如隐身模式）
  onWarning?: (message: string) => void;            // 警告信息回调
}

type InitModel = 'normal' | 'invisible'

```

### Widget定义

```TypeScript
type TWidgetType =
  | 'widget_pic' // 单个图片
  | 'subtitle_on' // 字幕
  | 'subtitle_off' // 字幕
  | any

/** UI 控件位置 */
interface IWidgetCommon {
  axis_id: number
  'x_location'?: number
  'y_location'?: number
  width?: number
  height?: number
}

interface IWidgetPic extends IWidgetCommon {
  image: string
}
interface IWidgetSubtitle extends IWidgetCommon {
  text: string
  axis_id: number
  type: TWidgetType
}

type IWidget =
  | IWidgetPic
  | IWidgetSubtitle
  | any

interface IRawWidgetData {
  type: string;
  data?: IWidget;
  text?: string;
  speech_id?: number;
  client_speak_id?: number;
}
```

## SSML 标签速查

| 标签 | 用途 | 示例 |
|-|-|-|
| `<speak>` | 根标签，所有内容包在里面 | `<speak>...</speak>` |
| `<break>` | 停顿 | `<break time="500ms"/>` |
| `<phoneme>` | 注音 | `<phoneme py="ei1 ai1">AI</phoneme>` |
| `<ue4event>` | SDK 内置事件（动作、行走） | `<ue4event><type>ka</type>...</ue4event>` |
| `<uievent>` | 应用层自定义事件（控件） | `<uievent><type>show_image</type>...</uievent>` |

### `<ue4event>`  type

| type | 用途 |
|-|-|
| `ka` | 关键动作（预设编排） |
| `ka_intent` | 意图动作（AI 实时生成） |
| `walk` | 行走 |
