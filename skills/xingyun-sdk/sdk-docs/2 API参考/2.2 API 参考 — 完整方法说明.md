# 2.2 API 参考 — 完整方法说明

## 核心生命周期方法

### `init(params)`

初始化 SDK。加载资源包、建立 WebSocket 连接、初始化渲染器。

```typescript
init(params: IInitParams): Promise<void>
```

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|-|-|-|-|
| `params.onDownloadProgress` | `(progress: number) => void` | **是** | 资源加载进度回调，`progress` 为 0-100 的进度值 |
| `params.initModel` | `InitModel` | 否 | 初始化模式。设为 `invisible` 可在启动时进入隐身模式 |

**返回值**：`Promise<void>`，初始化完成后 resolve。初始化失败时 reject 并抛出错误。

**异常处理**：

```javascript
try {
  await avatar.init({
    onDownloadProgress(progress) {
      console.log('加载进度:', progress + '%');
    },
  });
  console.log('初始化成功');
} catch (error) {
  // error 为 SDKError 实例
  console.error('初始化失败:', error.code, error.message);
}
```

### `destroy(stop_reason?)`

销毁 SDK 实例，释放所有资源。

```typescript
destroy(stop_reason?: string): Promise<void>
```

**参数**：

| 参数 | 类型 | 说明 |
|-|-|-|
| `stop_reason` | `string` | 销毁原因，用于服务端日志记录。 |

```javascript
// 页面卸载时销毁
window.addEventListener('beforeunload', () => {
  avatar.destroy('page_unload');
});

// 业务逻辑销毁
await avatar.destroy('user_logout');
```

---

### `destroyClient()`

仅销毁客户端资源，不通知服务端结束会话。

```typescript
destroyClient(): Promise<void>
```

适用场景：需要在客户端重新初始化但保持服务端会话时使用。

```javascript
await avatar.destroyClient();
// 可以重新 init（完成后自动启动渲染）
await avatar.init({
  onDownloadProgress(progress) {
    console.log('加载进度:', progress + '%');
  },
});
```

## 状态控制方法

以下方法控制数字人的行为状态，调用后会同步通知服务端。

### `idle()`

切换到空闲状态。数字人停止当前动作，进入静默 Idle 动画。

```typescript
idle(): void
```

### `interactiveidle()`

切换到交互空闲状态。与 `idle()` 类似，但表示数字人处于可交互的等待状态。

```typescript
interactiveidle(): void
```

**状态切换典型流程**：

```javascript
// 用户开始输入
avatar.listen();

// AI 回复到达，开始说话
avatar.speak('<speak>这是回复内容</speak>');

// 说话结束，回到交互空闲
// （由 onSpeakStateChange 回调中的 'end' 事件触发）
avatar.interactiveidle();
```

## 语音交互

### `speak(ssml, is_start?, is_end?, extra?)`

发送 SSML 文本，驱动数字人说话。

```typescript
speak(ssml: string, is_start?: boolean, is_end?: boolean, extra?: object): void
```

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|-|-|-|-|
| `ssml` | `string` | 是 | SSML 格式的文本。 |
| `is_start` | `boolean` | 否 | 是否为本次说话的第一段。默认 `true`。 |
| `is_end` | `boolean` | 否 | 是否为本次说话的最后一段。默认 `true`。 |
| `extra` | `object` | 否 | 额外参数，扩展信息，会透传到服务端。 |

**流式说话**：

当需要分段发送长文本时，使用 `is_start` 和 `is_end` 标记边界：

```javascript
// 第一段（开始）
avatar.speak('<speak>这是第一句话。</speak>', true, false);

// 中间段
avatar.speak('<speak>这是第二句话。</speak>', false, false);

// 最后一段（结束）
avatar.speak('<speak>这是最后一句话。</speak>', false, true);
```

**一次性说话**：

```javascript
// 等价于 speak(text, true, true)
avatar.speak('<speak>你好！</speak>');
```

### `interrupt(type)`

打断数字人当前说话。需要在初始化实例传入的设置中定义 `enableClientInterrupt: true`。

```typescript
interrupt(type: string): number
```

| 参数 | 类型 | 说明 |
|-|-|-|
| `type` | `string` | 打断来源标签，用于日志区分（`'user'`/`'user_speaking'`/`'speak'` 等）。除了 `'in_offline_mode'` 外，所有 type 行为完全相同。 |

**返回值**：`number`，打断操作的执行耗时（毫秒）。

```javascript
const avatar = new XmovAvatar({
  // ...
  enableClientInterrupt: true,
});

// 打断当前说话，获取耗时
const latency = avatar.interrupt('user');
console.log('打断耗时:', latency, 'ms');
```

## 显示控制

### `changeLayout(layout)`

动态修改数字人布局。

```typescript
changeLayout(layout: Layout): void
```

**参数**：`Layout` 对象

```javascript
avatar.changeLayout({
  container: { size: [360, 640] },
  avatar: {
    v_align: 'center',
    h_align: 'center',
    scale: 0.9,
    offset_x: 50,
    offset_y: 0,
  },
});
```

### `changeWalkConfig(walkConfig)`

动态修改行走动画配置。

```typescript
changeWalkConfig(walkConfig: WalkConfig): void
```

**参数**：`WalkConfig` 对象。

### `changeAvatarVisible(visible)`

显示或隐藏数字人 Canvas。

```typescript
changeAvatarVisible(visible: boolean): void
```

```javascript
// 隐藏数字人（Canvas 设为 display:none）
avatar.changeAvatarVisible(false);

// 重新显示
avatar.changeAvatarVisible(true);
```

> **注意**：此方法控制的是 Canvas 元素的可见性，不影响渲染循环。隐藏时渲染仍在进行。

### `switchInvisibleMode()`

切换隐身模式。隐身模式下渲染暂停、音频静音，数字人完全停止工作。

```typescript
switchInvisibleMode(): void
```

与 `changeAvatarVisible(false)` 的区别：

- `changeAvatarVisible(false)`：仅隐藏画面，渲染和音频继续
- `switchInvisibleMode()`：暂停渲染、停止音频，节省 CPU/GPU 资源

```javascript
// 进入隐身模式
avatar.switchInvisibleMode();
// 再次调用退出隐身模式
avatar.switchInvisibleMode();
```

## 音量与调试

### `setVolume(volume)`

设置音频音量。

```typescript
setVolume(volume: number): void
```

| 参数 | 类型 | 说明 |
|-|-|-|
| `volume` | `number` | 音量值，范围 `0.0`（静音）到 `1.0`（最大）。 |

```javascript
avatar.setVolume(0.5);  // 50% 音量
avatar.setVolume(0);    // 静音
avatar.setVolume(1);    // 最大音量
```

### `showDebugInfo()`

显示调试信息面板。需要在构造时设置 `enableDebugger: true`。

```typescript
showDebugInfo(): void
```

调试面板会显示：当前状态、帧率、网络质量、缓存队列长度等实时信息。

### `hideDebugInfo()`

隐藏调试信息面板。

```typescript
hideDebugInfo(): void
```

```javascript
const avatar = new XmovAvatar({
  // ...
  enableDebugger: true,
});

avatar.showDebugInfo();  // 显示调试面板
// ...
avatar.hideDebugInfo();  // 隐藏调试面板
```

## 状态查询

### `getStatus()`

获取当前数字人状态。

```typescript
getStatus(): AvatarStatus
```

**返回值**：`AvatarStatus` 枚举值。

```javascript
const status = avatar.getStatus();
if (status === AvatarStatus.online) {
  console.log('数字人在线');
}
```

### `getRenderState()`

获取当前渲染状态。

```typescript
getRenderState(): RenderState
```

**返回值**：`RenderState` 枚举值。

```javascript
const state = avatar.getRenderState();
if (state === RenderState.rendering) {
  console.log('正在渲染');
}
```
