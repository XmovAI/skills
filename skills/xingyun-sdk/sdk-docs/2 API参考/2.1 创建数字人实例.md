# 2.1 创建数字人实例

## 创建数字人实例

SDK导出的对象XmovAvatar，用于创建数字人渲染实例，其构造函数接受一个`options`配置对象。

```TypeScript
const avatar = new XmovAvatar(options: IAvatarOptions);
```

`IAvatarOptions`定义如下：

### 必填参数

| 参数 | 类型 | 说明 |
|-|-|-|
| `appId` | `string` | 应用 ID，由后端分配，用于身份识别。 |
| `appSecret` | `string` | 应用密钥，由后端分配，用于请求签名。 |
| `gatewayServer` | `string` | 网关服务地址，用于创建会话和获取资源。固定值：`https://nebula-agent.xingyun3d.com/user/v1/ttsa/session`。 |
| `onMessage` | `(error: SDKError) => void` | 错误/事件回调。SDK 内部的所有错误和重要事件都通过此回调上报。**必须实现。** |

### 容器配置

| 参数 | 类型 | 说明 |
|-|-|-|
| `containerId` | `string` | 容器元素的 CSS 选择器（如 `#avatar-container`）。 |
| `container` | `HTMLElement` | 容器 DOM 元素引用。 |

`containerId`和`container`至少填写一个，若都不填写，初始化会失败。若两个都填写，则优先取`container`

### 可选参数

| 参数 | 类型 | 默认值 | 说明 |
|-|-|-|-|
| `config` | `object` | `undefined` | 参考[运行时配置项](../3 高级功能/3.1 运行时配置项.md) |
| `enableClientInterrupt` | `boolean` | `false` | 是否启用客户端打断功能。启用后可通过 `interrupt()` 方法打断数字人说话。 |

### 回调参数

| 回调 | 类型 | 说明 |
|-|-|-|
| `onStatusChange` | `(status: AvatarStatus) => void` | 数字人状态变化回调。 |
| `onRenderChange` | `(state: RenderState) => void` | 渲染状态变化回调。 |
| `onVoiceStateChange` | `(state: string, duration?: number) => void` | 语音播放状态变化回调。`state` 为 `'start'` 或 `'end'`。 |
| `onSpeakStateChange` | `(state: string, client_speak_id: string \| number) => void` | 说话状态变化回调。`state` 为 `'speak_start'`、`'speak_end'` 或 `'speak_error'`。一段speak中会包含多段voice。 |
| `onWalkStateChange` | `(state: string) => void` | 行走状态变化回调。`state` 为 `'walk_start'` 或 `'walk_end'`。 |
| `onWidgetEvent` | `(data: IRawWidgetData) => void` | UI 组件事件回调。当服务端推送组件事件时触发。可参考[Widget 自定义渲染](../3%20高级功能/3.7%20Widget%20自定义渲染.md)章节。 |
| `proxyWidget` | `{ [key: string]: (data: any) => void }` | 自定义组件渲染代理。按组件类型注册自定义渲染函数。可参考[Widget 自定义渲染](../3%20高级功能/3.7%20Widget%20自定义渲染.md)章节。 |
| `onNetworkInfo` | `(info: INetworkInfo) => void` | 网络质量信息回调，包含 RTT、下行速率等指标。 |
| `onStartSessionWarning` | `(message: object) => void` | 会话配置警告（如参数不兼容）。触发此回调时，应检查创建实例时options配置的问题。 |
| `onFPSUpdate` | `(stats: FPSStats) => void` | 帧率统计更新回调。 |

### 使用示例

```javascript
const avatar = new XmovAvatar({
  containerId: '#avatar-container',
  appId: 'app-123456',
  appSecret: 'secret-abcdef',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa/session',
  enableClientInterrupt: true,

  // 错误回调
  onMessage(error) {
    console.error(`[SDK Error] ${error.code}: ${error.message}`);
  },

  // 状态回调
  onStatusChange(status) {
    console.log('Avatar status:', status);
  },

  onRenderChange(state) {
    console.log('Render state:', state);
  },

  onVoiceStateChange(state, duration) {
    console.log(`Voice ${state}`, duration ? `duration: ${duration}ms` : '');
  },

  onSpeakStateChange(state, speakId) {
    console.log(`Speak [${speakId}]: ${state}`);
  },

  // 网络监控
  onNetworkInfo(info) {
    console.log('Network:', info);
  },

  // 自定义组件渲染
  proxyWidget: {
    'custom_widget': (data) => {
      // 自行处理此类型的组件渲染
      console.log('Custom widget:', data);
    },
  },
});
```
