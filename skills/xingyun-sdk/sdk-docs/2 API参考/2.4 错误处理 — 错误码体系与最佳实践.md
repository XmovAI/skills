# 2.4 错误处理 — 错误码体系与最佳实践

## 错误码体系总览

SDK 使用统一的错误码体系，通过 `onMessage` 回调上报所有错误。错误码按模块分段：

| 错误码范围 | 分类 | 说明 |
|-|-|-|
| 10001 - 10004 | 初始化错误 | SDK 初始化过程中的错误 |
| 20001 - 20010 | 处理错误 | 运行时数据处理错误 |
| 30001 - 30007 | 资源错误 | 资源加载和缓存相关错误 |
| 40001 - 40007 | 解码错误 | 数据解码相关错误 |
| 50001 - 50004 | 网络错误 | 网络连接相关错误 |
| 60001 - 60007 | WebGL/上下文错误 | WebGL 上下文相关错误 |

### 错误对象结构

```typescript
interface SDKError {
  code: EErrorCode;      // 错误码
  message: string;       // 错误描述
  timestamp: number;     // 错误发生时间戳
  originalError?: any;   // 原始错误对象
}
```

## 初始化类错误（10001-10004）

| 错误码 | 常量名 | 说明 | 处理建议 |
|-|-|-|-|
| 10001 | `CONTAINER_NOT_FOUND` | 容器元素未找到 | 检查 `containerId` 选择器是否正确，确保 DOM 已加载 |
| 10002 | `CONNECT_SOCKET_ERROR` | WebSocket 连接错误 | 检查网络连接和服务端地址 |
| 10003 | `START_SESSION_ERROR` | 会话创建失败 | 检查 `appId` 和 `appSecret` 是否正确 |
| 10004 | `STOP_SESSION_ERROR` | 停止会话异常 | 查看具体错误信息 |

```javascript
onMessage(error) {
  switch (error.code) {
    case 10001:
      // 容器不存在，检查 DOM ID
      console.error('请检查 containerId 是否正确');
      break;
    case 10002:
      // WebSocket 连接失败
      console.error('无法连接到服务，请检查网络');
      break;
    case 10003:
      // 会话创建失败
      console.error('认证失败，请检查 appId 和 appSecret');
      break;
    case 10004:
      // 初始化异常
      console.error('初始化失败:', error.message);
      break;
  }
}
```

## 处理类错误（20001-20010）

| 错误码 | 常量名 | 说明 | 处理建议 |
|-|-|-|-|
| 20001 | `VIDEO_FRAME_EXTRACT_ERROR` | 视频帧提取失败 | 通常是视频数据损坏，SDK 会自动跳过 |
| 20002 | `INIT_WORKER_ERROR` | Web Worker 初始化失败 | 检查浏览器是否支持 Web Worker |
| 20003 | `PROCESS_VIDEO_STREAM_ERROR` | 视频流处理失败 | 通常是数据格式问题，SDK 会自动降级 |
| 20004 | `RENDER_BODY_ERROR` | 身体渲染错误 | 可能是 WebGL 资源不足 |
| 20005 | `RENDER_FACE_ERROR` | 面部渲染错误 | 可能是纹理或着色器问题 |
| 20006 | `RENDER_FACE_ERROR` | 面部渲染错误（备选） | 同 20005 |
| 20010 | `EVENT_WITHOUT_SPEECH_ID` | 事件缺少 speech ID | 服务端推送的事件数据格式问题 |

这些错误通常是运行时偶发的，SDK 内部会尽量容错处理（跳过错误帧、降级渲染等）。一般不需要用户特殊处理，但建议记录日志用于排查问题。

```javascript
onMessage(error) {
  if (error.code >= 20000 && error.code < 30000) {
    // 处理类错误，记录日志但通常不需要中断
    console.warn(`[处理错误] ${error.code}: ${error.message}`);
    logToServer('processing_error', error);
  }
}
```

## 资源类错误（30001-30007）

| 错误码 | 常量名 | 说明 | 处理建议 |
|-|-|-|-|
| 30001 | `BACKGROUND_IMAGE_LOAD_ERROR` | 背景图片加载失败 | 检查图片 URL 是否可访问 |
| 30002 | `FACE_BIN_LOAD_ERROR` | 面部资源加载失败 | 检查服务端资源包是否正常 |
| 30003 | `INVALID_BODY_NAME` | 身体数据名称无效 | 服务端配置问题 |
| 30004 | `VIDEO_DOWNLOAD_ERROR` | 视频下载失败 | 检查 CDN 或缓存服务地址 |
| 30005 | `BODY_DATA_EXPIRED` | 身体数据过期 | 服务端数据需要更新 |
| 30006 | `EVENT_SPEAK_START_EXPIRED` | 说话开始事件过期 | 事件到达时已超时 |
| 30007 | `EVENT_VOICE_START_EXPIRED` | 语音开始事件过期 | 事件到达时已超时 |

```javascript
onMessage(error) {
  switch (error.code) {
    case 30001:
      console.warn('背景图片加载失败，使用默认背景');
      break;
    case 30004:
      console.warn('视频下载失败，可能影响动画流畅度');
      break;
    case 30005:
      console.error('资源数据已过期，请刷新页面重新加载');
      // 可以提示用户刷新
      break;
  }
}
```

## 解码类错误（40001-40007）

| 错误码 | 常量名 | 说明 | 处理建议 |
|-|-|-|-|
| 40001 | `AUDIO_DECODE_ERROR` | 音频解码失败 | 音频数据可能损坏，SDK 会自动跳过 |
| 40002 | `FACE_DECODE_ERROR` | 面部数据解码失败 | 可能是 Protobuf/msgpack 版本不匹配 |
| 40003 | `VIDEO_DECODE_ERROR` | 视频解码失败 | 可能是浏览器不支持该视频编码格式 |
| 40004 | `EVENT_DECODE_ERROR` | 事件数据解码失败 | 数据格式问题 |
| 40005 | `INVALID_DATA_STRUCTURE` | 数据结构无效 | 服务端推送了异常数据 |
| 40006 | `TTSA_ERROR` | 通信层错误 | socket.io 通信异常 |
| 40007 | `AUDIO_DATA_EXPIRED` | 音频数据过期 | 音频数据到达时已超过播放时间 |

```javascript
onMessage(error) {
  if (error.code === 40003) {
    console.warn('视频解码失败，可能是浏览器兼容性问题');
    // 考虑提示用户切换浏览器
  }
}
```

## 网络类错误（50001-50004）

| 错误码 | 常量名 | 说明 | 处理建议 |
|-|-|-|-|
| 50001 | `OFFLINE` | 网络断开 | SDK 自动重连，UI 层可提示用户 |
| 50002 | `ONLINE` | 网络恢复 | 通知性事件，非错误 |
| 50003 | `RETRY` | 正在重连 | 通知性事件，包含当前重连次数 |
| 50004 | `BREAK` | 重连终止 | 所有重连尝试已耗尽，需要用户刷新 |

```javascript
onMessage(error) {
  switch (error.code) {
    case 50001:
      showNetworkTip('网络断开，正在尝试重连...');
      break;
    case 50002:
      hideNetworkTip();
      console.log('网络已恢复');
      break;
    case 50003:
      console.log(`正在重连... (第 ${error.data?.retryCount} 次)`);
      break;
    case 50004:
      showNetworkTip('网络连接失败，请刷新页面重试');
      break;
  }
}
```

### 重连机制

SDK 内置自动重连机制，重连期间，数字人进入离线模式，保证画面不中断。所有重连尝试都失败后，触发 `50004` 错误，此时需要用户手动刷新页面。

## WebGL/上下文错误（60001-60007）

| 错误码 | 常量名 | 说明 | 处理建议 |
|-|-|-|-|
| 60001 | `CONTEXT_LOST` | WebGL 上下文丢失 | GPU 资源被系统回收，SDK 自动恢复 |
| 60002 | `CONTEXT_RESTORED` | WebGL 上下文已恢复 | 通知性事件 |
| 60003 | `CONTEXT_RESTORE_TIMEOUT` | 上下文恢复超时 | 正在重试恢复 |
| 60004 | `CONTEXT_RECOVERED` | 上下文恢复成功 | 通知性事件 |
| 60005 | `CONTEXT_RECOVERY_FAILED` | 上下文恢复失败 | 可能需要刷新页面 |
| 60006 | `CONTEXT_RECOVERY_MAX_ATTEMPTS` | 达到最大恢复尝试次数 | 需要用户刷新页面 |
| 60007 | `EVENT_TRIGGERED` | 事件触发 | 上下文恢复过程中的事件 |

### WebGL 上下文丢失

WebGL 上下文丢失通常发生在以下情况：

- GPU 资源被系统回收（如移动端后台切换）
- 浏览器标签页长时间不活动
- 显卡驱动异常

SDK 内置了自动恢复机制，通过onMessage可监听感知到这些异常，可以由上层添加UI提示等。

```javascript
onMessage(error) {
  if (error.code === 60001) {
    console.warn('WebGL 上下文丢失，正在自动恢复...');
    // 可以显示一个 loading 提示
  } else if (error.code === 60004) {
    console.log('WebGL 上下文已恢复');
    // 隐藏 loading 提示
  } else if (error.code === 60006) {
    console.error('WebGL 恢复失败，请刷新页面');
    // 提示用户刷新
  }
}
```

## 错误处理最佳实践

### 完整的错误处理示例

```javascript
const avatar = new XmovAvatar({
  containerId: '#avatar-container',
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa/session',

  onMessage(error) {
    // 1. 记录所有错误
    logError(error);

    // 2. 根据严重程度分级处理
    const severity = getErrorSeverity(error.code);
    switch (severity) {
      case 'critical':
        // 致命错误，提示用户刷新
        showErrorDialog('发生严重错误，请刷新页面重试');
        break;
      case 'warning':
        // 警告，记录但不中断
        console.warn(`[Warning] ${error.code}: ${error.message}`);
        break;
      case 'info':
        // 通知性事件
        console.info(`[Info] ${error.code}: ${error.message}`);
        break;
    }
  },
});

function getErrorSeverity(code) {
  // 致命错误
  if ([10002, 10003, 10004, 50004, 60006].includes(code)) {
    return 'critical';
  }
  // 通知性事件
  if ([50002, 60002, 60004].includes(code)) {
    return 'info';
  }
  // 其他为警告
  return 'warning';
}
```

### 错误上报

建议将 SDK 错误上报到你的监控系统，便于后续分析：

```javascript
function logError(error) {
  // 上报到监控平台
  fetch('/api/error-log', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      code: error.code,
      message: error.message,
      data: error.data,
      timestamp: Date.now(),
      userAgent: navigator.userAgent,
      url: window.location.href,
    }),
  }).catch(() => {});
}
```
