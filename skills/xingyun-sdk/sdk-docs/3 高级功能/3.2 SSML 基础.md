# 3.2 SSML 基础

## SSML 基础 —— 所有高级功能的驱动语言

数字人的**播报、停顿、注音、关键动作、行走、自定义控件**全部由 SSML（语音合成标记语言）驱动。SDK 参考了微软 [Azure SSML 标准](https://learn.microsoft.com/zh-cn/azure/ai-services/speech-service/speech-synthesis-markup)，但做了简化适配。

> **一句话理解**：你在 `sdk.speak(ssml)` 里传入的每一段文字，都可以混合嵌入指令标签，数字人会按顺序边说边做动作、展示控件、移动位置。

### 根标签 `<speak>`

所有 SSML 内容必须包裹在 `<speak>` 标签中：

```xml
<speak>
  ... 内容和指令 ...
</speak>
```

### 子标签一览

| 标签 | 用途 | 所属类别 |
|-|-|-|
| `<break>` | 停顿 | 基础 |
| `<phoneme>` | 注音（多音字纠正） | 基础 |
| 纯文本 | 汉字 / 英文单词，正常播报 | 基础 |
| `<ue4event>` | SDK 内置事件：**关键动作（ka/ka_intent）、行走**（walk） | 动作 |
| `<uievent>` | 应用层自定义事件：**图片/视频/链接/文本卡片/背景音乐** | 控件 |

---

### 1. 停顿 `<break>`

在句子之间插入停顿：

```xml
<speak>
  第一句话。
  <break time="500ms"/>
  停半秒后第二句话。
</speak>
```

| 属性 | 说明 |
|-|-|
| `time` | 停顿时长，如 `500ms` / `1s` |

---

### 2. 注音 `<phoneme>`

给多音字/生僻字标注正确读音，TTS 按拼音发音：

```xml
<speak>
  这项<phoneme py="mei3 di4">美的</phoneme>技术正在改变世界。
</speak>
```

| 属性 | 说明 |
|-|-|
| `py` | 拼音标注，如 `mei3`（美三声）、`di4`（的四声），空格分隔多字 |

> 生僻字、特殊字符（全角双引号、`&` 等）可能导致服务端异常，建议预处理过滤。

---

### 3. 关键动作 `<ue4event type="ka">` / `ka_intent`

数字人的肢体动作通过 `<ue4event>` 嵌入 SSML。动作放在**哪句文本前面**，数字人就**边说那句话边做动作**：

```xml
<speak>
  真的很感谢大家。
  <ue4event>
    <type>ka</type>
    <data>
      <action_semantic>Elevate</action_semantic>
    </data>
  </ue4event>
  这个是我们今年的成绩。
</speak>
```

**两种动作类型**：

| type | 说明 |
|-|-|
| `ka` | 预设编排动作（`RightSide02` / `LeftSide` / `Elevate` / `KeyPoints`） |
| `ka_intent` | AI 实时生成的语义动作（`Pointscreen` 等） |

> ⚠️ 关键动作是**定制化功能**，需要角色制作时预置动作编排。

---

### 4. 行走 `<ue4event type="walk">`

行走同样是 SSML 指令，指定目标点位即可：

```xml
<speak>
  先看左边。
  <ue4event>
    <type>walk</type>
    <data>
      <target>left</target>
    </data>
  </ue4event>
  再看右边。
  <ue4event>
    <type>walk</type>
    <data>
      <target>right</target>
    </data>
  </ue4event>
  我走过来了。
</speak>
```

| 属性 | 说明 |
|-|-|
| `<target>` | 目标点位标签，必须在 `walk_config.walk_points` 中存在 |

> 行走前需先通过 `changeWalkConfig()` 配置点位，再发行走 SSML。



---

### 5. 自定义控件 `<uievent>`

说话时弹出图片、视频、链接、文本卡片，全部通过 `<uievent>` 下发：

```xml
<speak>
  请看大屏幕。
  <uievent>
    <type>show_image</type>
    <data>
      <image>https://example.com/poster.png</image>
      <title>新品发布</title>
    </data>
  </uievent>
</speak>
```

| type | 效果 |
|-|-|
| `show_image` | 展示图片卡片 |
| `show_video` | 播放视频 |
| `show_link` | 显示链接 |
| `show_text` | 展示文本卡片 |
| `bgm_start` | 播放背景音乐 |

> `<uievent>` 的数据由 `proxyWidget` 回调接收，SDK 不渲染控件 UI——应用自己渲染。

---

### 实战组合：一条 SSML 同时驱动动作、停顿、控件、行走

```xml
<speak>
  大家好，欢迎来到产品发布会。

  <ue4event><type>ka</type><data><action_semantic>Elevate</action_semantic></data></ue4event>
  首先介绍今天的主题。

  <break time="500ms"/>

  各位请看大屏幕。
  <uievent><type>show_image</type><data><image>https://example.com/slide.png</image><title>产品路线图</title></data></uievent>

  <ue4event><type>walk</type><data><target>K</target></data></ue4event>
  让我换个位置继续讲解。

  <phoneme py="gan4 xie4">感谢</phoneme>大家的聆听！
</speak>
```

**效果时间线**：说"大家好"→ 抬手做 Elevate 动作 → 介绍主题 → 停顿半秒 → 说"请看大屏幕"→ 弹出图片卡片 → 走到 K 点位 → 说"换个位置" → 播完。
