# 3.1 运行时配置项

本章节主要介绍数字人实例创建时，options可配置的一些高级用法，这些配置项也有专用API用于在运行时动态设置。

### 运行时配置项（`config` 字段）

`config` 字段通常由服务端在创建会话时返回，也可以在构造时传入覆盖。以下是支持的配置项：

| 配置项 | 类型 | 默认值 | 说明 |
|-|-|-|-|
| `layout` | `Layout` | 见下文 | 数字人布局配置。 |
| `walk_config` | `WalkConfig` | 见下文 | 行走动画配置。 |
| `background_img` | `string` | `''` | 背景图片 URL。设置后数字人将渲染在此背景图之上。 |
| `raw_audio` | `boolean` | `false` | 是否使用 PCM 原始音频模式。`true` 使用 AudioWorklet 播放 PCM 数据；`false` 使用 MSE 播放 WebM 数据。 |
| `init_events` | `Array` | `[]` | 初始化时要渲染的 UI 组件事件列表。 |

```javascript
const avatar = new XmovAvatar({
  // ... 必填参数
  config: {
    resolution: { width: 720, height: 1280 },
    background_img: 'https://example.com/bg.jpg',
    raw_audio: true,
    layout: {
      container: { size: [360, 640] },
      avatar: {
        v_align: 'bottom',
        h_align: 'center',
        scale: 1,
        offset_x: 0,
        offset_y: 0,
      },
    },
  },
});
```

## 布局控制（Layout）

`Layout` 配置控制数字人在容器中的位置和大小，采用嵌套结构。

### Layout 结构

```typescript
interface Layout {
  container: {
    size: number[]    // 容器尺寸 [width, height]
  },
  avatar: {
    v_align: string   // 垂直对齐：'top' | 'center' | 'bottom'
    h_align: string   // 水平对齐：'left' | 'center' | 'right'
    scale: number | string  // 缩放比例
    offset_x: number  // 水平偏移（像素）
    offset_y: number  // 垂直偏移（像素）
  }
}
```

### 属性说明

**container**

| 属性 | 类型 | 说明 |
|-|-|-|
| `size` | `number[]` | 容器尺寸，格式为 `[width, height]`。 |

**avatar**

| 属性 | 类型 | 说明 |
|-|-|-|
| `v_align` | `string` | 垂直对齐方式：`'top'`、`'center'`、`'bottom'`。 |
| `h_align` | `string` | 水平对齐方式：`'left'`、`'center'`、`'right'`。 |
| `scale` | `number \| string` | 缩放比例。`1` 为原始大小。 |
| `offset_x` | `number` | 水平偏移量（像素）。正值向右，负值向左。 |
| `offset_y` | `number` | 垂直偏移量（像素）。正值向下，负值向上。 |

### `scale` 取值说明

`layout.avatar.scale` 支持两种格式：

| 格式 | 示例 | 计算方式 |
|-|-|-|
| 数字 | `0.4` | 基于素材分辨率的缩放比例。如 1080×1920 分辨率下 `scale=0.4` → 数字人真实大小为 432×768。大部分素材为1080×1920(1080P)，可在星云工作台的调试功能中查看数字人分辨率。 |
| vh 字符串 | `"40vh"` | 相对容器高度的缩放比例。计算公式`vh值 / 100vh × 容器高度 / 素材分辨率高度`。如容器高 810、分辨率高 1920，`scale="40vh"` → 实际 scale ≈ 0.169 |

### 使用示例

```javascript
// 构造时设置
const avatar = new XmovAvatar({
  // ...
  config: {
    layout: {
      container: { size: [360, 640] },
      avatar: {
        v_align: 'bottom',
        h_align: 'center',
        scale: 0.8,
        offset_x: 0,
        offset_y: -20,
      },
    },
  },
});

// 运行时动态修改
avatar.changeLayout({
  container: { size: [360, 640] },
  avatar: {
    v_align: 'center',
    h_align: 'center',
    scale: 1,
    offset_x: 0,
    offset_y: 0,
  },
});
```

## 行走动画点位配置（WalkConfig）

`WalkConfig` 配置控制数字人的行走动画参数。行走相关介绍参考[行走动画控制](../3%20高级功能/3.4%20行走动画控制.md)

| 属性 | 类型 | 必填 | 说明 |
|-|-|-|-|
| `walk_points` | `{ [key: string]: number }` | **是** | 走路停靠点，key 为停靠点名称，value 为 x 坐标。 |
| `init_point` | `number` | 否 | 初始停靠点。 |

```javascript
// 构造时设置
const avatar = new XmovAvatar({
  // ...
  config: {
    walk_config: {
      walk_points: { left: 0, center: 400, right: 800 },
      init_point: 400,
    },
  },
});

// 运行时动态修改
avatar.changeWalkConfig({
  walk_points: { left: 0, center: 400, right: 800 },
  init_point: 400,
});
```
