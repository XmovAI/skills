# 3.8 客户端打断

## 客户端打断（Client Interrupt）

### `interrupt(type)` 方法

```typescript
interrupt(type: string): number  // 返回打断耗时（ms）
```

**`type` 参数**：打断来源的标签，用于日志区分：

| type 值 | 含义 | 示例场景 |
|-|-|-|
| `'user'` | 用户主动打断 | 点击打断按钮 |
| `'user_speaking'` | 语音打断 | ASR 检测到用户说话 |
| `'user_click'` | 点击打断 | UI 按钮触发 |
| `'speak'` | 新播报打断 | `speak()` 内部自动调用 |
| `'in_offline_mode'` | 离线模式打断 | SDK 内部下线时 |

> **除了 `'in_offline_mode'` 外，所有 type 的行为完全相同**。`type` 只是一个语义标签，不影响打断逻辑。返回值为打断操作的执行耗时（毫秒），可用于性能监控。

### 触发打断

```javascript
// 用户点击"打断"按钮
const latency = avatar.interrupt('user');
console.log('打断耗时:', latency, 'ms');

// 打断后进入聆听状态
avatar.listen();
```

## 打断相关初始化配置

数字人示例创建时，接受一个boolean配置项`enableClientInterrupt`，默认值为`false`。

```TypeScript
const avatar = new XmovAvatar({
  // ...
  enableClientInterrupt: true,
});
```

当此配置项设置为`true`时，`interrupt`的处理逻辑在客户端侧，响应的实时性更高，时延最短。配置项设置为false时，`interrupt`的处理逻辑在服务端侧，响应略有延迟，但数字人动作过渡流畅性更佳自然。
