# 3.7 Widget 自定义渲染

SDK 内置了默认的 Widget 事件处理器，开发者可以通过创建数字人实例时`options`中定义 `onWidgetEvent` 或 `proxyWidget` 自定义事件处理逻辑。通过该机制，可以在数字人播报过程中，自由灵活地渲染多媒体元素或处理自定义事件。

## Widget回调

Widget回调覆盖了SDK的系统事件及开发者自定义事件。

### 两种回调方法

SDK中提供了两种用于Widget回调的方法，`onWidgetEvent`和`proxyWidget`。两者的区别是onWidgetEvent会回调全部的事件，proxyWidget可按需定义指定类型事件的回调。当两者都显式定义时，`onWidgetEvent`优先级更高

#### onWidgetEvent定义示例

```TypeScript
onWidgetEvent(data) {
  console.log("Widget 事件:", data.type, data);
  // 自定义处理逻辑
}
```

#### proxyWidget定义示例

```JavaScript
proxyWidget: {
  subtitle_on(data) {
    // 自定义字幕显示逻辑
    console.log("Widget subtitle_on", data.type, data);
  },
  subtitle_off(data) {
    console.log("Widget subtitle_off", data?.type, data);
  },
  widget_pic(data) {
    console.log("Widget widget_pic", data?.type, data);
  },
}
```

### 内置功能重写

若在创建数字人实例时定义了`onWidgetEvent`或`proxyWidget.subtitle_on`时，SDK默认字幕不再展示，需要通过回调自行渲染。同理，定义了`onWidgetEvent`或`proxyWidget.widget_pic`时，场景图片也默认不再展示，需要在回调中自行渲染。

## 自定义事件

除了SDK内置事件外，为了满足多样的诉求，同样可以通过在SSML中灵活的自定义事件。以下介绍了常见数据类型的自定义事件方法：

### 1. 图片卡片 `show_image`

```xml
<speak>
  <uievent>
    <type>show_image</type>
    <data>
      <image>https://example.com/scene.png</image>
      <title>办公室场景</title>
    </data>
  </uievent>
  这是我们的办公室场景图片。
</speak>
```

| 字段 | 说明 |
|-|-|
| `<image>` | 图片 URL |
| `<title>` | 图片标题 |

### 2. 视频播放 `show_video`

```xml
<speak>
  <uievent>
    <type>show_video</type>
    <data>
      <video>https://example.com/demo.mp4</video>
      <cover>https://example.com/cover.jpg</cover>
      <title>产品介绍视频</title>
    </data>
  </uievent>
  让我为您播放产品介绍视频。
</speak>
```

| 字段 | 说明 |
|-|-|
| `<video>` | 视频 URL |
| `<cover>` | 封面图 URL |
| `<title>` | 视频标题 |

### 3. 链接卡片 `show_link`

```xml
<speak>
  <uievent>
    <type>show_link</type>
    <data>
      <url>https://xingyun3d.com/</url>
      <title>官方网站</title>
      <description>访问我们的官方网站了解更多信息</description>
      <image>https://xingyun3d.com/favicon.ico</image>
    </data>
  </uievent>
  您可以访问我们的官方网站了解更多详情。
</speak>
```

| 字段 | 说明 |
|-|-|
| `<url>` | 链接地址 |
| `<title>` | 链接标题 |
| `<description>` | 链接描述 |
| `<image>` | 图标/缩略图 URL |

### 4. 3D 模型 `show_model3d`

```xml
<speak>
  <uievent>
    <type>show_model3d</type>
    <data>
      <model_url>https://example.com/model.glb</model_url>
      <title>产品3D模型</title>
    </data>
  </uievent>
  这是产品的3D模型展示。
</speak>
```

| 字段 | 说明 |
|-|-|
| `<model_url>` | 3D 模型文件 URL（`.glb` 等格式） |
| `<title>` | 模型标题 |

### 5. 文本卡片 `show_text`

```xml
<speak>
  <uievent>
    <type>show_text</type>
    <data>
      <title>重要提示</title>
      <text_content>这是一段重要的文本内容，可以用于展示 FAQ、说明文档等。</text_content>
    </data>
  </uievent>
  让我为您展示重要信息。
</speak>
```

| 字段 | 说明 |
|-|-|
| `<title>` | 卡片标题 |
| `<text_content>` | 正文内容 |

### 6. 背景音乐 `bgm_start`

```xml
<speak>
  <uievent>
    <type>bgm_start</type>
    <data>
      <src>https://example.com/bgm.mp3</src>
      <title>背景音乐</title>
      <bgm_loop>true</bgm_loop>
      <bgm_volume>0.8</bgm_volume>
    </data>
  </uievent>
  为您播放背景音乐。
</speak>
```

| 字段 | 说明 |
|-|-|
| `<src>` | 音频文件 URL |
| `<title>` | 曲名 |
| `<bgm_loop>` | 是否循环播放，`true`/`false` |
| `<bgm_volume>` | 音量，0\~1 |

---

### 多控件组合

一条 SSML 可以同时嵌入多个 `<uievent>`，依次触发：

```xml
<speak>
  <uievent><type>show_image</type><data><image>https://example.com/scene.png</image><title>场景图片</title></data></uievent>
  首先展示场景图片。

  <uievent><type>show_video</type><data><video>https://example.com/demo.mp4</video><cover>https://example.com/cover.jpg</cover><title>产品介绍视频</title></data></uievent>
  让我为您播放产品介绍视频。

  <uievent><type>show_link</type><data><url>https://www.example.com</url><title>相关链接</title></data></uievent>
  然后提供相关链接。

  <uievent><type>show_model3d</type><data><model_url>https://example.com/model.glb</model_url><title>产品3D模型</title></data></uievent>
  这是产品的3D模型展示。
</speak>
```
