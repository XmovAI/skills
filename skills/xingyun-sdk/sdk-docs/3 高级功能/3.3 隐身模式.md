# 3.3 隐身模式

## 隐身模式

SDK 提供两种控制数字人可见性的 API，用途不同、可组合使用：

| API | 效果 | 后端推送 | 适用场景 |
|-|-|-|-|
| `switchInvisibleMode()` | 停止/恢复数字人渲染 + 通知后端停止/恢复数据推送 | 暂停/恢复推送 | 页面切走、需要节省带宽和 CPU |
| `changeAvatarVisible(visible)` | 纯 UI 隐藏/显示数字人 | 不受影响，继续推送 | 临时隐藏、淡入淡出 |

> **组合建议**：真正的"隐身" = `switchInvisibleMode()`（停渲染 + 省带宽） + `changeAvatarVisible(false)`（UI 隐藏）。唤醒时反过来调用即可。

### 9.1.1 switchInvisibleMode — 停止/恢复渲染与后端推送

`switchInvisibleMode()` 会同时做两件事：

1. **客户端**：暂停数字人渲染（Canvas 停止合成帧，CPU/GPU 占用降至极低）
2. **服务端**：通知后端暂停/恢复数据推送（`enterInvisibleMode()` / `exitInvisibleMode()`），节省带宽

**切换方式**：

```javascript
// 进入停止渲染模式（后端暂停推送）
avatar.switchInvisibleMode();

// 再次调用恢复渲染（后端恢复推送，并自动调用 listen() 进入聆听态）
avatar.switchInvisibleMode();
```

> `switchInvisibleMode()` 是开关式 API：当前在 `visible` / `online` 状态时调用 = 停止渲染；其他状态下调用 = 恢复渲染。

**状态回调顺序**：

进入时 SDK 依次触发：

```javascript
onStatusChange(6);  // 状态标记为隐身（invisible）
onRenderChange('pausing');    // 渲染暂停中
onRenderChange('paused');     // 渲染已暂停
```

退出时 SDK 依次触发：

```javascript
onRenderChange('resumed');    // 渲染恢复
onStatusChange(5);      // 回到可见状态（visible）
// 注意：恢复后 SDK 会自动调用 listen()，数字人进入聆听态
```

**延迟初始化**：

如果希望启动时就处于停止推送状态（不立即渲染、不给后端压力），在 `init()` 时设置 `initModel: 'invisible'`：

```javascript
const avatar = new XmovAvatar({
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'wss://...',
});

// 传入 invisible 初始化，SDK 完成后不渲染、不通知后端推送
await avatar.init({ initModel: 'invisible' });

// 需要显示时，调用 switchInvisibleMode() 恢复渲染 + 恢复后端推送
avatar.switchInvisibleMode();
```

### 9.1.2 changeAvatarVisible — 纯 UI 显示/隐藏

`changeAvatarVisible()` 只控制 Canvas 元素的可见性，**不影响渲染、不通知后端**：

```javascript
// 隐藏数字人（Canvas display:none，渲染和后端推送照常进行）
avatar.changeAvatarVisible(false);

// 显示数字人
avatar.changeAvatarVisible(true);
```

适用于需要临时隐藏但不想中断数据流的场景：淡入淡出动画、短暂遮挡、画中画模式切换等。

### 9.1.3 组合使用：完整的"隐身"与恢复

**进入隐身**：

```javascript
avatar.switchInvisibleMode();       // 停止渲染 + 暂停后端推送
avatar.changeAvatarVisible(false);  // 隐藏画面
```

**退出隐身（唤醒）**：

```javascript
avatar.changeAvatarVisible(true);   // 显示画面
avatar.switchInvisibleMode();       // 恢复渲染 + 恢复后端推送
```

### 9.1.4 页面切后台自动隐身

SDK 内部已经监听了 `visibilitychange` 事件（用于同步帧队列）。如需在页面切后台时自动进入停止推送状态，可自行叠加监听：

```javascript
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    // 页面切走：停渲染 + 停推送 + 隐藏
    if (avatar.getStatus() !== 6) {  // 非隐身（invisible）状态
      avatar.switchInvisibleMode();
      avatar.changeAvatarVisible(false);
    }
  } else {
    // 页面切回：显示 + 恢复渲染
    avatar.changeAvatarVisible(true);
    if (avatar.getStatus() === 6) {  // 隐身（invisible）状态
      avatar.switchInvisibleMode();
    }
  }
});
```

> **注意**：SDK 内置的 `visibilitychange` 监听不会自动调用隐身相关 API（该逻辑已被注释），所以需要自己去添加，不会和 SDK 内置监听冲突。
