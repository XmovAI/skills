# 3.6 情绪

## 情绪（Emotion）

数字人情绪分为面部情绪和音色情感：

| 维度 | 触发方式 | 说明 |
|-|-|-|
| **音色** | `speak()` 的 `extra.emotion` 直接指定情感标签 | **强制**使用指定音色情绪，无论文本内容如何 |
| **音色** | `speak()` 只传纯文本 | 大模型根据文本语义**自动推测**意图并匹配音色情绪 |
| **数字人表情** | `speak()` 的 `extra.emotion` 直接指定情感标签 | **强制**使用指定面部表情，无论文本内容如何 |
| **数字人表情** | `speak()` 只传纯文本 | 大模型根据文本语义**自动推测**意图并匹配面部表情 |

客户端通过 `speak()` 方法的 `extra.emotion` 参数传入**情感标签**，服务端根据标签同时调整数字人的**面部表情**和**语音语调**。

> **注意**：表情功能不是 SDK 客户端独立 API，而是通过 `speak()` 的 `extra.emotion` 字段下发给**服务端**处理。

### 两种表情触发方式

| 方式 | 如何触发 | 效果 |
|-|-|-|
| **显式传参** | `extra.emotion` 直接指定情感标签 | **强制**使用指定表情，无论文本内容如何 |
| **文本推测** | 不传 `emotion`，只传纯文本 | 大模型根据文本语义**自动推测**意图并匹配表情 |

**显式传参**：你传给什么表情，数字人就做什么表情——文本内容是次要的。

```javascript
// 文本说"好悲伤"，但 emotion 传了 happy → 数字人会开心地说这句话
avatar.speak('<speak>好悲伤啊...</speak>', true, true, { emotion: 'happy' });
```

**文本推测**：不传 `emotion`，服务端大模型根据文本**第一句话**自动推断情感并匹配对应表情。适合对白由 LLM 生成、表情跟着内容自然走的场景。

```javascript
// 不传 emotion → 服务端从"太棒了"推測出 happy，自动匹配开心表情
avatar.speak('<speak>太棒了！通过了！</speak>');
```

> ⚠️ **定制化功能**：表情属于**定制化角色功能**，需要角色制作时预置表情数据。示例角色中支持数字人表情的如「苏苏」；如需在其他角色上使用，请联系团队进行角色定制。

### 情感标签说明

数字人表情全量支持情感如下，不同数字人形象支持的表情范围不同，具体可在星云工作台中查看。

| emotion | 效果 |
|-|-|
| `happy` | 开心 / 积极 |
| `sad` | 悲伤 / 低落 |
| `angry` | 生气 / 严肃 |
| `surprised` | 惊讶 |
| `neutral` | 中性 / 默认 |

**音色**

需对应多情感音色支持，不同厂商 TTS 情感能力存在差异，自研 XMov TTS 支持全量情感如下（外厂 TTS 情感标签以对应厂商音色说明为准）。

| emotion | 效果 |
|-|-|
| `happy` | 开心 / 积极 |
| `sad` | 悲伤 / 低落 |
| `angry` | 生气 / 严肃 |
| `surprised` | 惊讶 |
| `neutral` | 中性 / 默认 |

### 完整示例

```javascript
// 指定开心语调
avatar.speak('<speak>恭喜你通过了面试！</speak>', true, true, { emotion: 'happy' });

// 指定严肃语调
avatar.speak('<speak>请注意以下安全事项。</speak>', true, true, { emotion: 'serious' });

// 不指定 emotion（服务端默认处理）
avatar.speak('<speak>今天的天气多云转晴。</speak>');
```

### 与关键动作的区别

| 能力 | 控制方式 | 作用域 |
|-|-|-|
| **表情**（emotion） | `speak()` 的 `extra.emotion` 参数 | 整句说话的语调和面部表情 |
| **关键动作**（KA） | SSML 中的 `<ue4event>` 标签 | 特定时刻的肢体手势 |

两者可以组合使用：关键动作控制**身体手势**，情感标签控制**面部表情和语调**。

```javascript
const ssml = `
<speak>
<ue4event><type>ka</type><data><action_semantic>Elevate</action_semantic></data></ue4event>
欢迎大家来到今天的发布会！
</speak>`;

// 关键动作（抬手） + 开心表情
avatar.speak(ssml, true, true, { emotion: 'excited' });
```
