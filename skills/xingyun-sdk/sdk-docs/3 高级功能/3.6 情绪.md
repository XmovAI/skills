# 3.6 情绪

本页适用于 `XmovAvatar` 渲染入口。角色表情、音色和情感支持由服务端与角色素材决定，SDK 源码不能证明某个情感标签必然有效。

## 第四参数的边界

公开 `speak()` 第四参数用于 `client_speak_id` 和 `client_frame`。公开类型声明不包含 `emotion`；不要把 `{ emotion: "happy" }` 当作可直接复制的 TypeScript 接入方式，也不要承诺指定标签一定同时改变语音与表情。定制服务若扩展该参数，需要单独确认服务端协议和客户端类型支持。

## Agent 入口

`XingyunAvatarAgent.speak()` 仅接受三个参数。会话级 TTS 配置见 [服务与配置](<../../e2esdk-docs/2 功能介绍/2.2 服务与配置.md>)；音色情感以 provider 和音色支持为准。

## 动作与情感

关键动作使用 SSML 中的 `<ue4event>` 标签，见 [关键动作](<3.5 关键动作.md>)。动作指令与服务端情感配置是不同能力，应分别验收。
