# 3.5 关键动作

## 关键动作（Key Action）

KA = Key Action，数字人的预设肢体动作。通过 SSML 中的 `<ue4event>` 标签嵌入，数字人会在播报**对应文本的同时**做出动作。

> **注意**：关键动作不是 SDK 客户端 API，而是通过 `<ue4event>` SSML 标签下发给**服务端**处理。服务端在合成语音的同时驱动数字人做出肢体动作。



### 两种 KA 类型

> ⚠️ **定制化功能**：关键动作和行走属于**定制化角色功能**，需要角色制作时生成对应资产。以下示例为角色「合耳」中支持的关键动作；角色支持的动作清单查询入口（功能待开放）。
> 
> 支持的全部动作清单可查阅[3.5.1 动作意图列表](3.5.1%20动作意图列表.md)

| 类型 | SSML 标签 | 定义 |
|-|-|-|
| `ka` | `<type>ka</type>` | 关键动作 |
| `ka_intent` | `<type>ka_intent</type>` | 关键动作意图，一个KA意图对应多个KA，在实际动作编排时KA意图会转化为具体KA |

### 1. 关键动作（ka）

`action_semantic` 为预置动作名（如 `wave_hand`、`bow`、`RightSide02`  等）

```xml
<speak>
  真的特别感谢大家。
  <ue4event>
    <type>ka</type>
    <data>
      <action_semantic>RightSide02</action_semantic> 
    </data>
  </ue4event>
  大家可以看向右上方。
</speak>
```

### 2. 动作意图（ka_intent）

`ka_intent` 为关键动作意图，在实际动作编排时后端根据意图自动匹配最合适的 KA 动作。

```xml
<ue4event>
  <type>ka_intent</type>
  <data>
    <ka_intent>Pointscreen</ka_intent>
  </data>
</ue4event>
```

### 动作与播报的时间线

SSML 中，动作标签放在**哪句文本前面**，数字人就**边说那句话边做动作**。文本说完，动作也结束。

⚠️距离过近的ka会被忽略。

```xml
<speak>
  第一句话没有动作。
  <ue4event><type>ka</type><data><action_semantic>Elevate</action_semantic></data></ue4event>
  第二句话伴随抬手动作。
  <ue4event><type>ka</type><data><action_semantic>KeyPoints</action_semantic></data></ue4event>
  第三句话伴随抓重点手势。
</speak>
```

### 在 speak() 中使用

动作标签直接写在 SSML 字符串中，通过 `speak()` 发送：

```javascript
const ssml = `
<speak>
  大家好，
  <ue4event><type>ka</type><data><action_semantic>KeyPoints</action_semantic></data></ue4event>
  今天有三个重点要跟大家分享。
</speak>`;
avatar.speak(ssml);
```

### 注意事项

- `ka` 动作列表可能随 SDK 版本更新而扩展，具体以服务端实际支持为准
- 一个 `<speak>` 中可以嵌入多个 `<ue4event>`，每个动作匹配紧随其后的文本段落
