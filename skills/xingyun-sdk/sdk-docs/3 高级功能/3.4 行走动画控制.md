# 3.4 行走动画控制

## 行走动画控制

行走动画允许数字人在水平方向上移动位置，适用于虚拟展厅、引导讲解等场景。

> ⚠️ **定制化功能**：行走属于**定制化角色功能**，需要角色制作时预置行走动画数据。示例角色中支持行走的如「合耳」；如需在其他角色上使用，请联系团队进行角色定制。

### 点位坐标系

点位（Walk Point） 是数字人在容器水平方向上的目标位置，以容器的X轴坐标（像素值）表示。

- 坐标系原点：容器最左侧边缘，即 `x = 0`
- 坐标系范围：`0` 到 `container_width`（容器宽度）
- 点位值：表示数字人Canvas左侧边缘在容器中的X坐标位置

### 配置

在初始化 `XmovAvatar` 实例时，通过 `walk_config` 字段配置点位：

```javascript
const avatar = new XmovAvatar({
  walk_config: {
    walk_points: {
      A: 0,      // 容器左边缘
      B: 320,
      C: 640,
      D: 960,
      E: 1280,
      F: 1600,
      G: 1920    // 容器右边缘
    },
    init_point: 320// 数字人初始位置 
  }
});
```

### 动态修改

运行时可通过 `changeWalkConfig()` 修改行走配置，适用于容器尺寸变化或场景切换：

> 注意：`changeWalkConfig()` 仅允许在数字人非行走状态下调用。若数字人正在行走中调用，配置更新将不生效，需等待行走结束后重试。

```javascript
avatar.changeWalkConfig({
  walk_points: {
    F: 0,
    G: 100,
    H: 200,
    I: 300,
    J: 400,
    K: 500,
    L: 600,
    M: 700,
    N: 800,
    O: 900,
    P: 1000,
    Q: 1100,
    R: 1200,
    S: 1300,
    T: 1400,
    U: 1500
  },
  init_point: 700
});
```

### 监听行走状态

通过 `onWalkStateChange` 回调监听数字人的行走生命周期：

```javascript
const avatar = new XmovAvatar({
  onWalkStateChange(state) {
    if (state === 'start') {
      console.log('数字人开始行走');
    } else if (state === 'end') {
      console.log('数字人到达目的地');
    }
  },
});
```

### 通过 SSML 触发行走

配置好点位后，在 SSML 中嵌入 `<ue4event type="walk">` 命令，数字人会在播报到对应位置时走向目标点：

```xml
<speak>
  先看左边。
  <ue4event>
    <type>walk</type>
    <data>
      <target>F</target>
    </data>
  </ue4event>
  我走过来了。
</speak>
```

| 属性 | 说明 |
|-|-|
| `<type>` | 固定为 `walk` |
| `<target>` | 目标点位标签，必须在 `walk_config.walk_points` 中存在，否则行走指令将被忽略。 |

**边走边说**：行走标签放在文本前面，数字人会边走边播报紧随其后的句子：

```javascript
const ssml = `
<speak>
  <ue4event><type>walk</type><data><target>G</target></data></ue4event>
  我正在走过来。
</speak>`;
avatar.speak(ssml);
```

> **⚠️ 重要：**
> 
> 1. 必须先调用 `changeWalkConfig()` 配置好点位，再发行走 SSML。
> 2. `target` 标签必须在 `walk_points` 中存在，否则行走指令不生效。
> 3. 当 `enableClientInterrupt` = `false` 时，播报过程中无法执行行走指令。
