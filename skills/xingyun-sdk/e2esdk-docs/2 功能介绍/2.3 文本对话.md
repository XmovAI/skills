# 2.3 文本对话

本节说明如何发起文本对话、接收大模型流式回复，以及如何判断一轮对话已完成播报。

## 发起对话：`ask()`

`ask()` 发起一次 Brain（大模型）对话：文本送入 Brain，回复经具身智能体播报。

```ts
ask(text: string): Promise<void>
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | `string` | 是 | 发送给 Brain 的文本 |

**返回值**：`Promise<void>`，仅表示请求已写入传输通道，**不代表本轮播报已经结束**。

```javascript
agent.ask("介绍一下这个产品");
```

**注意**：`ask()` 要求 Agent 处于 `running` 状态。若需要「跳过 Brain、直接播报固定文本」，请使用 `speak()`（见 `2.5 具身智能体播报与 SSML`）。

## 接收流式回复：`onLLMResponse`

大模型回复通过 `agentCallbacks.onLLMResponse` 流式返回：先多条 `event: "chunk"` 分片，最后一条 `event: "done"` 表示本轮回复结束。

```ts
onLLMResponse: (response: AgentLLMResponse) => void

// response:
//   { event: "chunk"; text?: string; isFirst?: boolean; raw?: unknown }
// | { event: "done"; text?: string; usage?: AgentLLMUsage; raw?: unknown }
```

`AgentLLMUsage` 的字段：

```ts
interface AgentLLMUsage {
  promptTokens: number;      // 提示词 token 数
  completionTokens: number;  // 生成 token 数
  totalTokens: number;       // 总 token 数
  cachedTokens: number;      // 命中缓存的 token 数
}
```

**流式拼接示例**

```javascript
const agent = new XingyunAvatarAgent({
  // 省略公共参数
  agentCallbacks: {
    onLLMResponse(response) {
      if (response.event === "chunk") {
        // 分片：追加到字幕/正文
        replyBox.textContent += response.text ?? "";
      } else if (response.event === "done") {
        const u = response.usage;
        console.log(
          `本轮结束，token：${u?.promptTokens} / ${u?.completionTokens} / ${u?.totalTokens}（缓存 ${u?.cachedTokens}）`,
        );
      }
    },
  },
});
```

## 对话业务状态：`onConversationChange`

`onConversationChange` 反映一轮对话所处的业务阶段，是判断「一轮对话完成」的主要信号。

```ts
onConversationChange: (event: AgentConversationEvent) => void
// event: { state: AgentConversationState; text?: string; raw?: unknown }
```

```ts
type AgentConversationState =
  | "idle" | "asking" | "speaking" | "completed" | "failed";
```

| `state` | 含义 |
|---------|------|
| `idle` | 空闲，未在对话 |
| `asking` | 已发起 `ask()` / ASR 识别，等待 Brain 回复 |
| `speaking` | 具身智能体正在播报回复 |
| `completed` | 本轮对话播报完成 |
| `failed` | 本轮对话失败 |

```javascript
agentCallbacks: {
  onConversationChange(event) {
    if (event.state === "completed") {
      inputBox.disabled = false; // 允许下一次提问
    }
  },
}
```

## 判断一轮对话完成

`ask()` 返回只表示消息已写入，因此判断「播报是否结束」应监听状态回调，**不要**依赖 `ask()` 的 Promise 完成时机。

推荐两种方式：

1. **用 `onConversationChange`**：监听到 `speaking` 表示开始播报，`completed` 表示本轮完成。
2. **用 `agentCallbacks.onSpeakStateChange`**：监听具身智能体播报状态进入结束态。

```javascript
const agent = new XingyunAvatarAgent({
  // 省略公共参数
  agentCallbacks: {
    onConversationChange(event) {
      conversationBadge.textContent = event.state;
    },
    // 注意：此处在 agentCallbacks 内，参数为对象 { state, clientSpeakId, raw }
    onSpeakStateChange(event) {
      if (event.state === "speak_end") {
        console.log("播报结束", event.clientSpeakId);
      }
    },
  },
});
```

## 完整示例：打字聊天

```javascript
import XingyunAvatarAgent from "@xmov/avatar/agent";

const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  onMessage: console.error,
  agentCallbacks: {
    onLLMResponse(response) {
      if (response.event === "chunk") replyBox.textContent += response.text ?? "";
    },
    onConversationChange(event) {
      if (event.state === "asking") sendBtn.disabled = true;
      if (event.state === "completed" || event.state === "failed") {
        sendBtn.disabled = false;
      }
    },
  },
});

agent.init();

sendBtn.addEventListener("click", async () => {
  const text = inputBox.value.trim();
  if (!text) return;
  replyBox.textContent = "";
  inputBox.value = "";
  await agent.ask(text); // 回复经 onLLMResponse 流式返回
});
```
