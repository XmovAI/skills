# 2.11 调试与监控

`XingyunAvatarAgent` 提供音量调节、调试信息面板、网络指标与帧率监控能力，便于开发期排查与运行期观测。

## 音量控制

### 方法：`setVolume()`

设置数字人播报音量，不影响系统全局音量。

**签名**

```ts
setVolume(volume: number): void
```

**参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `volume` | `number` | 是 | — | 音量，取值 `0.0`–`1.0` |

**示例**

```javascript
agent.setVolume(0.5); // 50% 音量
agent.setVolume(0);   // 静音
```

## 调试信息面板

`showDebugInfo()` 与 `hideDebugInfo()` 控制数字人画布上的调试浮层。该能力需要构造参数 `enableDebugger: true`，否则调用无效。

```javascript
const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  enableDebugger: true, // 开启后 showDebugInfo 才生效
  onMessage(error) {
    console.error("数字人错误", error.code, error.message);
  },
});

agent.showDebugInfo(); // 显示调试浮层
agent.hideDebugInfo(); // 隐藏调试浮层
```

**签名**

```ts
showDebugInfo(): void
hideDebugInfo(): void
```

> 调试浮层通常用于开发期，上线前建议关闭 `enableDebugger` 与 `showDebugInfo()`，避免影响渲染性能与界面观感。

## 网络指标

### 回调：`onNetworkInfo(info)`

周期性回传网络质量指标，可据此做弱网提示或降级。该回调在构造参数顶层与 `agentCallbacks` 内均有同名版本，字段结构一致。

```ts
onNetworkInfo: (info: INetworkInfo) => void

interface INetworkInfo {
  rtt: number;             // 打包往返时延
  downlink: number;        // 下行带宽
  networkStatus: boolean;  // 网络是否可用
}
```

```javascript
const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  onMessage(error) {
    console.error("数字人错误", error.code, error.message);
  },
  onNetworkInfo(info) {
    netBadge.textContent = info.rtt < 200 ? "网络良好" : "网络波动";
  },
});
```

## 帧率统计

### 回调：`onFPSUpdate(stats)`

回传数字人渲染帧率统计，用于观测渲染性能。

```ts
onFPSUpdate: (stats: FPSStats) => void

interface FPSStats {
  [key: string]: unknown; // 帧率统计信息
}
```

```javascript
const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  onMessage(error) {
    console.error("数字人错误", error.code, error.message);
  },
  onFPSUpdate(stats) {
    console.log("渲染帧率", stats);
  },
});
```

## 会话标识

### 方法：`getSessionId()`

返回当前会话 ID，可用于日志关联、工单上报与问题定位。

**签名**

```ts
getSessionId(): string | undefined
```

**返回值**：当前会话 ID；尚未建立会话或会话已结束时返回 `undefined`。

**示例**

```javascript
console.log("当前会话", agent.getSessionId());
```

## 组合示例

```javascript
import XingyunAvatarAgent from "@xmov/avatar/agent";

const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  enableDebugger: true,
  onMessage(error) {
    console.error("数字人错误", error.code, error.message);
  },
  onNetworkInfo(info) {
    document.querySelector("#rtt").textContent = `${info.rtt}ms`;
  },
  agentCallbacks: {
    onError(error) {
      console.error("Agent 错误", error.code, error.message);
    },
  },
});

agent.init();

agent.setVolume(0.8);
agent.showDebugInfo();
console.log("会话 ID", agent.getSessionId());
```

> 以上回调均需遵循「回调内不抛异常、异步自行 `catch`」的约定。
