# 2.8 动作、行走与表情

本节说明如何让数字人在播报中做出肢体动作、行走，以及如何通过情绪标签控制数字人的面部表情与语音语调。

## 关键动作（Key Action）

数字人的肢体动作通过 SSML 中的 `<ue4event>` 标签下发，动作放在**哪句文本前面**，数字人就**边说那句话边做动作**。支持两种动作类型：

| type | 说明 |
|------|------|
| `ka` | 预设关键动作（预置动作编排名，如 `Elevate` / `KeyPoints` / `RightSide02`） |
| `ka_intent` | 关键动作意图：一个意图对应多个具体 KA，编排时由后端自动匹配最合适的实际动作 |

### 预设动作（`ka`）

`type="ka"` 通过 `data.action_semantic` 指定预置动作名：

```xml
<speak>
  真的特别感谢大家。
  <ue4event>
    <type>ka</type>
    <data>
      <action_semantic>RightSide02</action_semantic>
    </data>
  </ue4event>
  大家可以看向右上方。
</speak>
```

### 动作意图（`ka_intent`）

`type="ka_intent"` 通过 `data.ka_intent` 指定语义动作意图：

```xml
<speak>
  大家可以看向我的手指方向。
  <ue4event>
    <type>ka_intent</type>
    <data>
      <ka_intent>Pointscreen</ka_intent>
    </data>
  </ue4event>
  谢谢大家。
</speak>
```

### 动作意图列表（主要条目）

每个角色实际支持的动作意图数量存在差异，下表为主要意图条目，完整清单以服务端 / 星云平台为准：

| 动作意图中文名 | 动作意图 |
|----------------|----------|
| 拱手示意礼节 | `FistSalute` |
| 鼓掌 | `ClapHands` |
| 欢迎 | `Welcome` |
| 感谢 | `ThankYou` |
| 禁止 | `Prohibit` |
| 抓重点 | `KeyPoints` |
| 提升 | `Elevate` |
| 点赞 | `Like` |
| 再见 | `Goodbye` |
| 打招呼 | `Hello` |
| 指自己 | `PointingSelf` |
| 惊喜 | `Surprise` |
| 指屏幕 | `Pointscreen` |
| 比心 | `Heart` |
| 指观众 | `PointAudience` |
| 鼓舞激励 | `Encourage` |
| 握手 | `Shakehands` |
| 击掌 | `Highfive` |
| 跳舞 | `Dance` |

> 关键动作是**定制化功能**，需要角色制作时预置动作编排。距离过近的多个 `ka` 会被忽略，一个 `<speak>` 中可嵌入多个 `<ue4event>` 依次生效。

## 行走

`XingyunAvatarAgent` 通过 `config.walk_config` 配置行走点位，运行期可用 `changeWalkConfig()` 动态更新。`WalkConfig` 字段如下：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `walk_points` | `{ [key: string]: number }` | 是 | 行走停靠点，key 为停靠点名称，value 为 x 坐标（像素） |
| `init_point` | `number` | 否 | 初始停靠点（x 坐标） |

> 行走属于**定制化角色功能**，需要角色制作时预置行走动画数据。坐标系原点为容器最左侧（x=0），范围为 0 到容器宽度。

### 构造时配置

```javascript
const agent = new XingyunAvatarAgent({
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session',
  onMessage(error) { console.error(error); },
  config: {
    walk_config: {
      walk_points: { left: 0, center: 400, right: 800 },
      init_point: 400,
    },
  },
});
```

### 运行时动态更新

> 注意：`changeWalkConfig()` 仅在数字人**非行走状态**下生效，正在行走时调用不生效，需等待行走结束后重试。

```javascript
agent.changeWalkConfig({
  walk_points: { left: 0, center: 400, right: 800 },
  init_point: 400,
});
```

### 通过 SSML 触发行走

配置好点位后，在 SSML 中嵌入 `<ue4event type="walk">`，`target` 指定目标停靠点名称，数字人会在播报到该处时走向目标点：

```xml
<speak>
  我先走到右边。
  <ue4event>
    <type>walk</type>
    <data>
      <target>right</target>
    </data>
  </ue4event>
  我过来了。
</speak>
```

| 属性 | 说明 |
|------|------|
| `<type>` | 固定为 `walk` |
| `<target>` | 目标停靠点名称，必须存在于 `walk_points`，否则行走指令被忽略 |

### 监听行走状态

通过 `onWalkStateChange` 感知行走开始 / 结束：

```javascript
const agent = new XingyunAvatarAgent({
  // ... 必填参数
  onWalkStateChange(state) {
    if (state === 'start') {
      console.log('数字人开始行走');
    } else if (state === 'end') {
      console.log('数字人到达目的地');
    }
  },
});
```

## 情绪（Emotion）

`XingyunAvatarAgent` 通过 `speak()` 的 `extra.emotion` 参数传入情感标签，服务端据此同时调整数字人的**面部表情**与**语音语调**。

### 两种触发方式

| 方式 | 如何触发 | 效果 |
|------|----------|------|
| 显式传参 | `extra.emotion` 直接指定情感标签 | 强制使用指定表情 / 语调，文本内容次要 |
| 文本推测 | 不传 `emotion`，只传文本 | 大模型根据文本语义自动推测并匹配表情 / 语调 |

**显式传参**：

```javascript
// 文本说"好悲伤"，但 emotion 传了 happy → 数字人开心地说这句话
agent.speak('<speak>好悲伤啊...</speak>', true, true, { emotion: 'happy' });
```

**文本推测**：

```javascript
// 不传 emotion → 服务端从"太棒了"推测出 happy，自动匹配开心表情
agent.speak('<speak>太棒了！通过了！</speak>');
```

### 情感标签

| emotion | 效果 |
|---------|------|
| `happy` | 开心 / 积极 |
| `sad` | 悲伤 / 低落 |
| `angry` | 生气 / 严肃 |
| `surprised` | 惊讶 |
| `neutral` | 中性 / 默认 |

> 表情与多情感音色均属**定制化角色功能**；不同数字人形象与 TTS 厂商支持的情感范围存在差异，外厂 TTS 情感标签以对应厂商音色说明为准。

### 与关键动作组合使用

关键动作控制**身体手势**，情感标签控制**面部表情与语调**，两者可同时使用：

```javascript
const ssml = `
<speak>
  <ue4event><type>ka</type><data><action_semantic>Elevate</action_semantic></data></ue4event>
  欢迎大家来到今天的发布会！
</speak>`;

agent.speak(ssml, true, true, { emotion: 'happy' }); // 抬手 + 开心表情
```
