# 2.1 连接与生命周期

本节说明 `XingyunAvatarAgent` 从创建、初始化到销毁的完整生命周期，以及如何用 `getAgentState()` / `getASRState()` 驱动页面交互。

## 生命周期概览

一个典型实例的完整生命周期如下：

```
new XingyunAvatarAgent(...)  →  init()  →  running（可直接对话/识别）
                                    │
                              destroy()（销毁，不可复用）
```

关键约定：

- **`init()` 返回即已进入 `running`**。初始化完成后可直接调用 `ask()` / `startASR()`，无需额外的启动步骤。
- **`destroy()` 释放全部资源，调用后实例不可再初始化或复用**。

## 初始化：`init()`

建立会话与连接、下载并准备数字人资源。初始化完成后自动进入 `running` 状态。

**签名**

```ts
init(params?: XingyunAvatarAgentInitParams): Promise<void>
```

**参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `params.onDownloadProgress` | `(progress: number) => void` | 否 | 无 | 数字人资源下载进度回调，`progress` 取值 0–100 |
| `params.initModel` | `'normal' \| 'invisible'` | 否 | `'normal'` | `'invisible'` 时以隐身状态初始化，见 `2.7 布局与隐身` |

**返回值**：`Promise<void>`，会话创建结果；返回即代表初始化成功。

**示例**

```javascript
const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  onMessage(error) {
    console.error("数字人错误", error.code, error.message);
  },
});

agent
  .init({
    onDownloadProgress(progress) {
      console.log("资源下载进度", progress.toFixed(0) + "%");
    },
  })
  .then(() => {
    // 此处已进入 running，可直接对话 / 识别
    console.log("当前状态", agent.getAgentState()); // "running"
  })
  .catch((error) => {
    console.error("初始化失败", error);
  });
```

**注意**：`init()` 失败会拒绝 Promise，此时应销毁实例后重建，不要直接复用失败实例。

## 销毁：`destroy()`

释放全部资源：停止播报与识别、关闭连接、释放内存。调用后实例不可再初始化或复用。页面退出 / 组件卸载时应调用；只删除 DOM 容器不会释放麦克风与连接资源。

```ts
destroy(reason?: string): Promise<void>
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `reason` | `string` | 否 | `"user"` | 销毁原因 |

```javascript
// 页面退出时销毁
window.addEventListener("beforeunload", () => {
  void agent.destroy("page_unload");
});

// 组件卸载时销毁（Vue 示例）
import { onBeforeUnmount } from "vue";
onBeforeUnmount(async () => {
  await agent.destroy("component_unmount");
});
```

## 用状态驱动页面

页面应订阅 `agentCallbacks.onAgentStateChange` / `onASRStateChange`，并结合 `getAgentState()` / `getASRState()` 的当前值更新 UI。

**读取当前状态**

```ts
getAgentState(): AgentState       // 新接入统一使用
getASRState(): AgentASRState
```

**订阅状态变化**

```javascript
const agent = new XingyunAvatarAgent({
  // 省略其他参数
  agentCallbacks: {
    onAgentStateChange(state) {
      setLoading(state === "initializing" || state === "reconnecting");
      setControlsDisabled(state !== "running");
    },
    onASRStateChange(state) {
      setMicActive(state === "listening");
    },
  },
});
```

**Agent 状态 → UI 建议**

| `AgentState` | 含义 | UI 建议 |
|--------------|------|---------|
| `idle` | 实例刚创建 | 显示加载占位，等待 `init()` |
| `initializing` | 正在初始化连接与资源 | 显示加载态，禁用对话与 ASR |
| `ready` | 内部过渡态（首次初始化中进入 `running` 前） | 与 `initializing` 同样处理 |
| `running` | 可用 | 允许发起对话与 ASR |
| `reconnecting` | 断线重连中 | 禁用新操作，提示「连接恢复中」 |
| `failed` | 不可恢复错误 | 展示错误并引导重新初始化 |
| `destroyed` | 已销毁 | 不再调用当前实例 |

**ASR 状态 → UI 建议**

| `AgentASRState` | 含义 | UI 建议 |
|-----------------|------|---------|
| `idle` | 未开启识别 | 麦克风按钮置灰/可点击 |
| `requesting-permission` | 正在申请麦克风权限 | 按钮进入等待态 |
| `starting` | 正在启动采集 | 按钮显示「启动中」 |
| `listening` | 正在识别 | 麦克风高亮，显示实时字幕 |
| `stopping` | 正在停止 | 按钮显示「停止中」 |
| `failed` | 启动失败 | 展示错误（详见 `2.12 错误处理`） |
