# 2.6 打断与状态控制

本节说明如何打断具身智能体当前播报，并通过 `idle()` / `interactiveidle()` / `listen()` 在待机、交互待机、聆听三种姿态间切换。

## 方法：`interrupt()`

`XingyunAvatarAgent` 提供 `interrupt()` 立即打断当前具身智能体播报，返回打断操作的执行耗时（毫秒）。

**签名**

```ts
interrupt(): number
```

**参数**：无。旧版 `XmovAvatar.interrupt(type)` 的参数不适用于 Agent；需要记录来源时，在业务日志中记录。

**返回值**：`number`，打断操作的耗时（毫秒），可用于性能监控。

**示例**

```javascript
interruptButton.addEventListener('click', () => {
  const latency = agent.interrupt();
  console.log('打断耗时:', latency, 'ms');

  agent.listen(); // 打断后进入聆听状态，等待用户说话
});
```

> 打断不会关闭麦克风或 ASR。若打断后需要结束监听，请额外调用 `stopASR()`。

## 配置：`enableClientInterrupt`

`enableClientInterrupt` 默认 `true`，用于渲染层的客户端打断策略。显式 `agent.interrupt()` 会发送 E2E 打断并执行本地清理；设为 `false` 不会禁用这个公开方法。服务端动作衔接效果需要结合角色和服务配置验收。

## 姿态切换：`idle()` / `interactiveidle()` / `listen()`

`XingyunAvatarAgent` 提供三个姿态切换方法，用于控制具身智能体的默认表现：

| 方法 | 签名 | 姿态含义 | 典型场景 |
|------|------|----------|----------|
| `idle()` | `idle(): void` | 待机姿态（默认姿态） | 无交互、空闲挂机 |
| `interactiveidle()` | `interactiveidle(): void` | 交互待机姿态（区别于普通待机） | 一轮对话结束后恢复可交互的等待态 |
| `listen()` | `listen(): void` | 聆听姿态 | 对话中等待用户说话 |

**示例**

```javascript
// 创建实例时注册回调；不要给 agent 实例赋 onSpeakStateChange 属性
const agent = new XingyunAvatarAgent({
  containerId: '#agent-avatar',
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session',
  onMessage: console.error,
  onSpeakStateChange(state) {
    if (state === 'speak_end') agent.interactiveidle();
  },
});
await agent.init();

// 用户点击打断，具身智能体开始聆听
agent.interrupt();
agent.listen();

// 长时间无交互，回到普通待机
setTimeout(() => agent.idle(), 30_000);
```

> 三个方法均只改变具身智能体的播放姿态，不影响 ASR 是否开启。是否进入聆听的麦克风状态由 `startASR()` / `stopASR()` 控制。

## 打断与状态切换的配合建议

常见的「打断 → 聆听 → 播报 → 待机」闭环：

```javascript
agentCallbacks: {
  onConversationChange(event) {
    if (event.state === 'speaking') {
      // 具身智能体开始播报
    } else if (event.state === 'completed') {
      agent.interactiveidle(); // 播报完成，进入交互待机
    } else if (event.state === 'interrupted') {
      agent.listen();          // 被打断，进入聆听
    }
  },
},
```
