# 2.6 打断与状态控制

本节说明如何打断数字人当前播报，并通过 `idle()` / `interactiveidle()` / `listen()` 在待机、交互待机、聆听三种姿态间切换。

## 方法：`interrupt()`

`XingyunAvatarAgent` 提供 `interrupt()` 立即打断当前数字人播报，返回打断操作的执行耗时（毫秒）。

**签名**

```ts
interrupt(type: string): number
```

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | `string` | 是 | 打断来源的语义标签，用于日志区分，不影响打断行为 |

常用 `type` 取值：

| type 值 | 含义 | 示例场景 |
|---------|------|----------|
| `'user'` | 用户主动打断 | 点击打断按钮 |
| `'user_speaking'` | 语音打断 | ASR 检测到用户抢话 |
| `'user_click'` | 点击打断 | UI 按钮触发 |
| `'speak'` | 新播报打断 | 新的 `speak()` 调用打断上一段 |
| `'in_offline_mode'` | 离线模式打断 | SDK 内部进入离线时触发 |

**返回值**：`number`，打断操作的耗时（毫秒），可用于性能监控。

**示例**

```javascript
interruptButton.addEventListener('click', () => {
  const latency = agent.interrupt('user_click');
  console.log('打断耗时:', latency, 'ms');

  agent.listen(); // 打断后进入聆听状态，等待用户说话
});
```

> 打断不会关闭麦克风或 ASR。若打断后需要结束监听，请额外调用 `stopASR()`。

## 配置：`enableClientInterrupt`

打断行为受构造参数 `enableClientInterrupt` 控制，默认值为 **`true`**。

```javascript
const agent = new XingyunAvatarAgent({
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session',
  onMessage(error) { console.error(error); },
  enableClientInterrupt: true, // 默认即为 true，可省略
});
```

| 取值 | 打断处理位置 | 特点 |
|------|--------------|------|
| `true`（默认） | 客户端本地处理 | 响应实时性最高，时延最短 |
| `false` | 服务端处理 | 响应略有延迟，但数字人动作过渡更自然流畅 |

## 姿态切换：`idle()` / `interactiveidle()` / `listen()`

`XingyunAvatarAgent` 提供三个姿态切换方法，用于控制数字人的默认表现：

| 方法 | 签名 | 姿态含义 | 典型场景 |
|------|------|----------|----------|
| `idle()` | `idle(): void` | 待机姿态（默认姿态） | 无交互、空闲挂机 |
| `interactiveidle()` | `interactiveidle(): void` | 交互待机姿态（区别于普通待机） | 一轮对话结束后恢复可交互的等待态 |
| `listen()` | `listen(): void` | 聆听姿态 | 对话中等待用户说话 |

**示例**

```javascript
// 一轮播报结束，进入交互待机
agent.onSpeakStateChange = (state) => {
  if (state === 'speak_end') agent.interactiveidle();
};

// 用户点击打断，数字人开始聆听
agent.interrupt('user_click');
agent.listen();

// 长时间无交互，回到普通待机
setTimeout(() => agent.idle(), 30_000);
```

> 三个方法均只改变数字人的播放姿态，不影响 ASR 是否开启。是否进入聆听的麦克风状态由 `startASR()` / `stopASR()` 控制。

## 打断与状态切换的配合建议

常见的「打断 → 聆听 → 播报 → 待机」闭环：

```javascript
agentCallbacks: {
  onConversationChange(event) {
    if (event.state === 'speaking') {
      // 数字人开始播报
    } else if (event.state === 'completed') {
      agent.interactiveidle(); // 播报完成，进入交互待机
    } else if (event.state === 'interrupted') {
      agent.listen();          // 被打断，进入聆听
    }
  },
},
```
