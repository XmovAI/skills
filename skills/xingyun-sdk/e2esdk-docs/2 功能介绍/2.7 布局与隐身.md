# 2.7 布局与隐身

本节说明如何通过布局配置调整数字人在容器中的位置、缩放与对齐，以及如何隐藏、隐身数字人以节省带宽与渲染开销。

## 布局：`config.layout` 与 `changeLayout()`

`XingyunAvatarAgent` 提供布局能力，通过构造参数 `config.layout` 设置初始布局，运行期用 `changeLayout()` 动态调整。`Layout` 字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `container` | `{ size: number[] }` | 容器尺寸，`size` 为 `[width, height]` |
| `avatar` | `object` | 数字人位姿，子字段见下表 |
| `avatar.v_align` | `string` | 垂直对齐：`'top' \| 'center' \| 'bottom'` |
| `avatar.h_align` | `string` | 水平对齐：`'left' \| 'center' \| 'right'` |
| `avatar.scale` | `number \| string` | 缩放：数字倍率或 `vh` 单位字符串 |
| `avatar.offset_x` | `number` | 水平偏移（像素），正值向右 |
| `avatar.offset_y` | `number` | 垂直偏移（像素），正值向下 |

### `scale` 取值说明

| 格式 | 示例 | 说明 |
|------|------|------|
| 数字倍率 | `0.4` | 基于素材分辨率的缩放比例。如 1080×1920 素材下 `scale=0.4` → 数字人真实大小约 432×768 |
| vh 字符串 | `"40vh"` | 相对容器高度的缩放：`"40vh"` 表示数字人高度约为容器高度的 40% |

### 构造时设置

```javascript
const agent = new XingyunAvatarAgent({
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session',
  onMessage(error) { console.error(error); },
  config: {
    layout: {
      container: { size: [360, 640] },
      avatar: {
        v_align: 'bottom',
        h_align: 'center',
        scale: 0.8,
        offset_x: 0,
        offset_y: -20,
      },
    },
  },
});
```

### 运行时动态调整

```javascript
agent.changeLayout({
  container: { size: [360, 640] },
  avatar: {
    v_align: 'center',
    h_align: 'center',
    scale: '40vh',
    offset_x: 0,
    offset_y: 0,
  },
});
```

## 可见性：`changeAvatarVisible()`

`XingyunAvatarAgent` 提供 `changeAvatarVisible()` 控制数字人画面的显隐。它只影响画面显示，**不停止渲染、不通知后端**，数据照常推送。

```javascript
agent.changeAvatarVisible(false); // 隐藏画面（渲染与后端推送照常）
agent.changeAvatarVisible(true);  // 显示画面
```

适用于淡入淡出、短暂遮挡、画中画切换等只想临时藏起画面、但不想中断数据流的场景。

## 隐身模式：`switchInvisibleMode()`

`switchInvisibleMode()` 是开关式 API，会同时做两件事：

1. **客户端**：暂停 / 恢复数字人渲染（停止合成帧，CPU / GPU 占用降至极低）。
2. **服务端**：通知后端暂停 / 恢复数据推送，节省带宽。

```javascript
// 进入隐身：停止渲染 + 暂停后端推送
agent.switchInvisibleMode();

// 再次调用：恢复渲染 + 恢复后端推送（并自动进入 listen() 聆听态）
agent.switchInvisibleMode();
```

**切换时的状态回调顺序**（可经 `onStatusChange` / `onRenderChange` 感知）：

进入隐身：

```javascript
onStatusChange('invisible'); // AvatarStatus.invisible === 6
onRenderChange('pausing');
onRenderChange('paused');
```

退出隐身：

```javascript
onRenderChange('resumed');
onStatusChange('visible');   // AvatarStatus.visible === 5
```

### 真正的「隐身」：组合使用

纯 UI 隐藏与停推送互不影响，两者组合才能同时省画面与省带宽：

```javascript
// 进入隐身
agent.switchInvisibleMode();       // 停止渲染 + 暂停推送
agent.changeAvatarVisible(false);  // 隐藏画面

// 退出隐身（唤醒）
agent.changeAvatarVisible(true);   // 显示画面
agent.switchInvisibleMode();       // 恢复渲染 + 恢复推送
```

## 延迟隐身初始化：`initModel: 'invisible'`

若希望启动时即处于「不渲染、不推送」状态，在 `init()` 时传入 `initModel: 'invisible'`：

```javascript
agent.init({ initModel: 'invisible' });
// 初始化完成后不渲染、不通知后端推送

// 需要显示时，调用 switchInvisibleMode() 恢复渲染 + 恢复推送
agent.switchInvisibleMode();
```

## 页面切后台自动隐身

SDK 内部已监听 `visibilitychange`（用于同步帧队列），但不会自动触发隐身。可在业务侧自行叠加，实现切后台省资源：

```javascript
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    // 页面切走：停渲染 + 停推送 + 隐藏
    if (agent.getStatus() !== 6 /* invisible */) {
      agent.switchInvisibleMode();
      agent.changeAvatarVisible(false);
    }
  } else {
    // 页面切回：显示 + 恢复渲染
    agent.changeAvatarVisible(true);
    if (agent.getStatus() === 6 /* invisible */) {
      agent.switchInvisibleMode();
    }
  }
});
```
