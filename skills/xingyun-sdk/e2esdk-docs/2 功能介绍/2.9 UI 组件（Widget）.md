# 2.9 UI 组件（Widget）

本节说明如何通过 Widget 机制在数字人播报过程中渲染多媒体元素与处理自定义事件：SSML 中的 `<uievent>` 下发事件，客户端用 `onWidgetEvent` 或 `proxyWidget` 接收并自行渲染。

## 回调：`onWidgetEvent` 与 `proxyWidget`

`XingyunAvatarAgent` 提供两种 Widget 事件回调，均挂在构造参数顶层：

| 回调 | 说明 |
|------|------|
| `onWidgetEvent` | 接收**全部** Widget 事件，`data` 为 `IRawWidgetData`（至少含 `type` 字段） |
| `proxyWidget` | 按事件 `type` 分发到指定处理函数，可按需定义 |

当两者同时显式定义时，`onWidgetEvent` **优先级更高**。

**`onWidgetEvent` 示例**：

```javascript
onWidgetEvent(data) {
  console.log('Widget 事件:', data.type, data);
  // 自定义处理逻辑
}
```

**`proxyWidget` 示例**：

```javascript
proxyWidget: {
  subtitle_on(data) {
    console.log('字幕开始', data);
  },
  subtitle_off(data) {
    console.log('字幕结束', data);
  },
  widget_pic(data) {
    console.log('场景图片', data);
  },
}
```

## 内置事件

SDK 内置了以下常用 Widget 事件。**注意**：一旦定义了 `onWidgetEvent`，或定义了 `proxyWidget` 中对应的内置事件处理函数，SDK 的默认渲染（默认字幕 / 场景图片）将不再展示，需要在回调中自行渲染。

| 事件 type | 触发时机 | 说明 |
|-----------|----------|------|
| `subtitle_on` | 字幕开始时 | 默认携带 `text`、`speech_id` 等字段 |
| `subtitle_off` | 字幕结束时 | 携带 `speech_id` 等字段 |
| `widget_pic` | 数字人形象 / 场景图下发时 | 默认携带图片 `image` 等字段 |

```javascript
const agent = new XingyunAvatarAgent({
  appId: 'your-app-id',
  appSecret: 'your-app-secret',
  gatewayServer: 'https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session',
  onMessage(error) { console.error(error); },

  proxyWidget: {
    subtitle_on(data) {
      // 自行渲染字幕
      subtitleEl.textContent = data.text;
      subtitleEl.style.display = 'block';
    },
    subtitle_off() {
      subtitleEl.style.display = 'none';
    },
    widget_pic(data) {
      // 自行渲染场景图
      sceneImg.src = data.image;
    },
  },
});
```

## 自定义事件

除内置事件外，还可以在 SSML 中用 `<uievent>` 下发自定义控件事件，由 `proxyWidget`（或 `onWidgetEvent`）接收后自行渲染 UI。

### 1. 图片卡片 `show_image`

```xml
<speak>
  <uievent>
    <type>show_image</type>
    <data>
      <image>https://example.com/poster.png</image>
      <title>新品发布</title>
    </data>
  </uievent>
  这是我们的海报。
</speak>
```

| 字段 | 说明 |
|------|------|
| `<image>` | 图片 URL |
| `<title>` | 图片标题 |

### 2. 视频播放 `show_video`

```xml
<uievent>
  <type>show_video</type>
  <data>
    <video>https://example.com/demo.mp4</video>
    <cover>https://example.com/cover.jpg</cover>
    <title>产品介绍视频</title>
  </data>
</uievent>
```

| 字段 | 说明 |
|------|------|
| `<video>` | 视频 URL |
| `<cover>` | 封面图 URL |
| `<title>` | 视频标题 |

### 3. 链接卡片 `show_link`

```xml
<uievent>
  <type>show_link</type>
  <data>
    <url>https://example.com/</url>
    <title>官方网站</title>
    <description>了解更多信息</description>
    <image>https://example.com/favicon.ico</image>
  </data>
</uievent>
```

| 字段 | 说明 |
|------|------|
| `<url>` | 链接地址 |
| `<title>` | 链接标题 |
| `<description>` | 链接描述 |
| `<image>` | 图标 / 缩略图 URL |

### 4. 3D 模型 `show_model3d`

```xml
<uievent>
  <type>show_model3d</type>
  <data>
    <model_url>https://example.com/model.glb</model_url>
    <title>产品3D模型</title>
  </data>
</uievent>
```

| 字段 | 说明 |
|------|------|
| `<model_url>` | 3D 模型文件 URL（`.glb` 等） |
| `<title>` | 模型标题 |

### 5. 文本卡片 `show_text`

```xml
<uievent>
  <type>show_text</type>
  <data>
    <title>重要提示</title>
    <text_content>这是一段重要文本，可用于 FAQ、说明等。</text_content>
  </data>
</uievent>
```

| 字段 | 说明 |
|------|------|
| `<title>` | 卡片标题 |
| `<text_content>` | 正文内容 |

### 6. 背景音乐 `bgm_start`

```xml
<uievent>
  <type>bgm_start</type>
  <data>
    <src>https://example.com/bgm.mp3</src>
    <title>背景音乐</title>
    <bgm_loop>true</bgm_loop>
    <bgm_volume>0.8</bgm_volume>
  </data>
</uievent>
```

| 字段 | 说明 |
|------|------|
| `<src>` | 音频文件 URL |
| `<title>` | 曲名 |
| `<bgm_loop>` | 是否循环播放，`true` / `false` |
| `<bgm_volume>` | 音量，0~1 |

### 多控件组合

一条 SSML 可同时嵌入多个 `<uievent>`，依次触发：

```xml
<speak>
  <uievent><type>show_image</type><data><image>https://example.com/scene.png</image><title>场景图片</title></data></uievent>
  首先展示场景图片。

  <uievent><type>show_video</type><data><video>https://example.com/demo.mp4</video><cover>https://example.com/cover.jpg</cover><title>产品介绍视频</title></data></uievent>
  再播放产品视频。

  <uievent><type>show_link</type><data><url>https://example.com</url><title>相关链接</title></data></uievent>
  最后提供相关链接。
</speak>
```

## 接收自定义事件并渲染

自定义事件与内置事件一样，最终进入 `proxyWidget` 对应 `type` 的处理函数（或 `onWidgetEvent` 全量回调）：

```javascript
proxyWidget: {
  show_image(data) { showImageCard(data.image, data.title); },
  show_video(data) { playVideo(data.video, data.cover, data.title); },
  show_link(data)  { showLinkCard(data.url, data.title, data.description, data.image); },
  show_text(data)  { showTextCard(data.title, data.text_content); },
  show_model3d(data) { showModel(data.model_url, data.title); },
  bgm_start(data)  { playBgm(data.src, data.bgm_volume, data.bgm_loop); },
}
```
