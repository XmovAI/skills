# 2.12 错误处理

`XingyunAvatarAgent` 有两条独立的错误通道，分别覆盖不同层级，接入时**必须同时处理**：

| 通道 | 位置 | 错误结构 | 覆盖范围 |
|------|------|----------|----------|
| `onMessage` | 构造参数顶层 | `SDKError`（数字码） | 数字人渲染、会话、解码、网络、WebGL |
| `onError` | `agentCallbacks` 内 | `AgentError`（字符串码 + 域） | Agent、ASR、Brain、网络、配额 |

## 数字人层错误：`onMessage(SDKError)`

数字人渲染与会话层的底层错误，通过构造参数顶层的 `onMessage` 返回。`code` 为数字码，按码段区分层级。

```ts
interface SDKError {
  code: number;           // 错误码
  message: string;        // 错误信息
  timestamp: number;      // 时间戳
  originalError?: unknown; // 原始错误
}
```

| 码段 | 含义 |
|------|------|
| `10001`–`10004` | 初始化错误 |
| `20001`–`20010` | 处理错误 |
| `30001`–`30007` | 资源错误 |
| `40001`–`40007` | 解码错误 |
| `50001`–`50004` | 网络错误 |
| `60001`–`60007` | WebGL / 上下文错误 |

```javascript
onMessage(error) {
  console.error("数字人错误", error.code, error.message, error.originalError);
}
```

## Agent 层错误：`onError(AgentError)`

Agent、ASR、Brain、网络与配额等错误，通过 `agentCallbacks.onError` 返回。`code` 为字符串码，并附带 `domain` 归类与 `retryable` 提示。

```ts
interface AgentError {
  code: string;                    // 字符串码
  message: string;                 // 错误信息
  domain: AgentErrorDomain;        // 错误域
  retryable?: boolean;             // 是否可重试
  cause?: unknown;                 // 原始原因
}

type AgentErrorDomain = "permission" | "network" | "asr" | "brain" | "ttsa" | "quota" | "sdk";
```

### 各域含义与处理建议

| 域 | 含义 | 典型错误码 | 处理建议 |
|----|------|------------|----------|
| `permission` | 麦克风等处权限被拒 | — | 引导用户在浏览器地址栏授权后重试 |
| `network` | E2E 连接、发送、重连失败 | `E2E_SOCKET_ERROR`、`E2E_SEND_FAILED`、`E2E_AUDIO_SEND_FAILED`、`E2E_RECONNECTING`、`E2E_RECONNECT_EXHAUSTED`、`E2E_CLOSE_<code>` | 依赖自动重连；耗尽后销毁并检查网络后重新初始化 |
| `asr` | ASR / 麦克风 / 编码失败 | `MICROPHONE_ERROR`、`MEDIA_RECORDER_ERROR`、`AUDIO_WEBM_OPUS_UNSUPPORTED`、`AGENT_ASR_STOP_FAILED` | 能力类不可重试，需换浏览器或配置；可重试项在用户手势下重新 `startASR()` |
| `brain` | Brain / LLM 服务错误 | 后端按 `domain` 映射 | 查看 `message`，必要时调整 `brain_config` |
| `ttsa` | 数字人渲染服务错误 | 后端按 `domain` 映射 | 查看会话返回，确认 TTSA 配置有效 |
| `quota` | 配额超限 | 对应 `E2E_CLOSE_4009` | 不自动重试，联系项目方扩容 |
| `sdk` | SDK 本地初始化等错误 | `AGENT_INIT_FAILED` | 查看 `cause`，失败实例不可复用 |

> `retryable` 表示「适合由业务重新发起操作」，**不代表 SDK 一定会自动重试**。E2E 断线是否自动重连由 close code 与 `reconnect` 配置共同决定。

## WebSocket 关闭码

E2E 控制面 WebSocket 关闭时，`close code` 决定后续行为：

| 关闭码 | 含义 | 处理 |
|--------|------|------|
| `1001` / `1006` / `1011` / `1012` / `1013` / `1014` | 网络 / 服务异常 | 自动重连 |
| `1000` | 正常关闭 | 用户主动销毁时正常；运行中出现视为终止 |
| `4000` | 路径未知 | 不重连 |
| `4001` | token 无效 | 不重连 |
| `4002` | session 不存在 | 不重连 |
| `4009` | 配额超限 | 不重连，不自动重试 |
| `4010` | 服务端主动断开 | 不重连 |

## 完整示例

同时实现两个错误入口，并遵守「回调内不抛异常、异步自行 `catch`」：

```javascript
import XingyunAvatarAgent from "@xmov/avatar/agent";

const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",

  // 数字人渲染 / 会话 / 底层错误
  onMessage(error) {
    console.error("[SDKError]", error.code, error.message, error.originalError);
    showBanner(`数字人异常：${error.message}`);
  },

  agentCallbacks: {
    // Agent / ASR / Brain / 网络 / 配额错误
    onError(error) {
      console.error("[AgentError]", error.code, error.domain, error.message);
      switch (error.domain) {
        case "permission":
          showBanner("麦克风权限被拒绝，请授权后重试");
          break;
        case "asr":
          if (error.retryable) {
            showBanner(`识别异常，可重试（${error.code}）`);
          } else {
            showBanner(`当前浏览器不支持语音（${error.code}）`);
          }
          break;
        case "network":
          showBanner(`网络异常：${error.message}`);
          break;
        case "quota":
          showBanner(`配额不足：${error.message}`);
          break;
        default:
          showBanner(`服务异常：${error.message}`);
      }
      // 异步落库自行捕获，避免 Promise 拒绝未被处理
      void reportErrorAsync(error).catch(console.error);
    },
  },
});
```

## 回调使用约定

- 回调内**不要抛出异常**，也不要做耗时的同步计算；业务回调的异常不会由 SDK 统一隔离。
- 回调内若需异步操作（如上报、落库、提示），自行 `catch`，避免 Promise 拒绝未被处理。
- 深度依赖当前状态时，优先在回调内取用 `getAgentState()` / `getASRState()` 的当前值。
