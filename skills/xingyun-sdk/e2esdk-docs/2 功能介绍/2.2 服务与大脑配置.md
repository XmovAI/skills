# 2.2 服务与大脑配置

本节说明如何通过构造参数配置 ASR、Brain 与功能开关。这些配置随统一 Session 请求一并提交给服务端。

> **安全提示：** asr_config、brain_config配置包含敏感的密钥设置，因此SDK中的设置仅用于本地测试或安全的私有环境使用，请勿用于生产环境造成安全风险。如需在生产环境定制，请在星云平台应用管理中配置ASR和Brain。

## 配置总览

所有服务配置均为构造参数的可选字段，与 `appId`、`gatewayServer` 同级传入：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `asr_config` | `Record<string, unknown>` | 无 | ASR 服务 JSON 配置 |
| `brain_config` | `AgentBrainConfig` | 无 | Brain（大模型）服务 JSON 配置 |
| `features` | `AgentFeatures` | 无 | Agent 功能开关，与 `asr_config` 同级发送 |

## 配置说明

- **空对象 `{}` = 未配置**。`asr_config`、`brain_config`、`features` 传入 `{}` 均视为未配置，使用平台提供的默认设置。

## ASR 配置：`asr_config`

ASR 识别服务的 JSON 配置，具体字段由项目方提供。

#### asr_config 结构

```javascript
{
  "provider": "xmov|doubao|tencent",
  "base_url": "wss://...",
  "headers": { "app_id": "...", "secret_key": "..." },   // doubao: resource_id/access_token/app_id
  "request": { "vad_tail_sil": 600 }
}
```

**初始化接入**

```javascript
const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  asr_config: {
    provider: "custom-asr",
  },
  onMessage: console.error,
});
```

## Brain 配置：`brain_config`

大模型（Brain）服务的 JSON 配置。

#### **brain_config 结构**

```javascript
{
  // 通用 openai 协议的LLM服务可以使用 openai_compatible
  // anthropic 协议的 使用 anthropic
  "provider": "openai_compatible|anthropic|youling|coze|dify|doubao|qwen|youyan_agent|openai|deepseek",
  "base_url": "...",
  "api_key": "...",
  "model": "...",
  "preset": "...",
  "history_length": 5,
  "extra_body": {}
 }
```

```javascript
const agent = new XingyunAvatarAgent({
  // 省略公共参数
  brain_config: {
    provider: "openai-compatible",
    extra_body: {
      thinking: { type: "disabled" },
    },
  },
  onMessage: console.error,
});
```

### `extra_body`

`brain_config.extra_body` 是可选 JSON 对象：

- SDK **只在调用方显式配置时透传**，不会自动补 `{}`。
- **仅用于 OpenAI-compatible 模型接口**的额外请求参数透传；youling、dify、coze 等应用 API 暂不适配。
- 空对象 `{}` 等同于未配置。

```ts
interface AgentBrainConfig extends Record<string, unknown> {
  extra_body?: Record<string, unknown>; // 仅 OpenAI-compatible 后端下发
}
```

## 功能开关：`features`

### features 参数

| 参数 | 默认值 | 说明 | 适用场景 |
|------|--------|------|---------|
| `auto_send_asr_to_llm` | `true` | 是否将 ASR 识别结果自动发送给大模型。设置为 `false` 时，ASR 结果不会自动进入大模型处理链路。 | 适合标准语音对话，用户说完后直接触发大模型回复。录音转写、人工确认后提问或需要业务侧审核 ASR 文本时，可以设置为 `false`，收到最终识别结果后再调用 `ask()`。 |
| `anti_interference.semantic_judge_enabled` | `true` | 是否启用抗干扰语义判断。 | 适合展厅、商场、直播、电视声或多人交谈等容易收到无关语音的环境，用于减少背景对话和非目标内容触发大模型。安静环境或不需要语义过滤时可以关闭。 |
| `vad_merge_mode` | `true` | 是否启用 VAD 合并模式。用于控制服务端是否合并被短暂停顿切开的语音片段。 | 适合自然对话、长句输入，以及用户说话时经常思考或停顿的场景，可减少一句话被拆成多次 ASR 结果或多次触发大模型。短口令、固定指令等更关注结束响应速度的场景，可以根据服务端策略关闭。 |
| `volume_and_repetition_text_detection` | `true` | 是否启用音量和重复文本检测。 | 适合远场拾音、用户音量较小、设备回声或相同内容被连续识别的场景，用于辅助发现低音量输入和重复识别问题。录音环境稳定，或业务已经自行处理重复文本时可以关闭。 |

`features` 用于控制 Agent 的抗干扰与语音检测能力，字段如下：

```ts
interface AgentFeatures {
  anti_interference?: {
    semantic_judge_enabled?: boolean;   // 语义判干扰（防播报被闲聊误触发）
  };
  vad_merge_mode?: boolean;             // 控制服务端是否合并被短暂停顿切开的语音片段。
  volume_and_repetition_text_detection?: boolean; // 音量与重复文本检测
  auto_send_asr_to_llm?: boolean;  // ASR 识别结果直接发送大模型
}
```

```javascript
const agent = new XingyunAvatarAgent({
  // 省略公共参数
  features: {
    anti_interference: {
      semantic_judge_enabled: false,
    },
    vad_merge_mode: true,
    volume_and_repetition_text_detection: false,
  },
});
```
