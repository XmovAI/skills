# 2.2 服务与大脑配置

本节说明如何通过构造参数配置 ASR、TTS、Brain 与功能开关。这些配置随统一 Session 请求一并提交给服务端。

> **安全提示：** asr_config、tts_config、brain_config 配置可能包含厂商密钥，因此SDK中的设置仅用于本地测试或安全的私有环境使用，请勿用于生产环境造成安全风险。如需在生产环境定制，请在星云平台应用管理中配置ASR和Brain。

## 配置总览

所有服务配置均为构造参数的可选字段，与 `appId`、`gatewayServer` 同级传入：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `asr_id` / `llm_id` | `number` | 无 | 平台配置 ID，分别用于 ASR / Brain |
| `tts_config` | `Record<string, unknown>` | 无 | TTS 服务 JSON 配置 |
| `extras` | `Record<string, unknown>` | 无 | 服务端约定的扩展配置 |
| `session_speak_req_id` | `0 \| 1` | `1` | 无开场白设 0，有开场白设 1 |
| `asr_config` | `Record<string, unknown>` | 无 | ASR 服务 JSON 配置 |
| `brain_config` | `AgentBrainConfig` | 无 | Brain（大模型）服务 JSON 配置 |
| `features` | `AgentFeatures` | 无 | Agent 功能开关，与 `asr_config` 同级发送 |

## 配置说明

- **空对象 `{}` = 未配置**。`asr_config`、`tts_config`、`brain_config`、`features`、`extras` 传入 `{}` 均视为未配置，使用平台提供的默认设置。

- `asr_id` 与非空 `asr_config` 不能同时传；`llm_id` 与非空 `brain_config` 不能同时传，冲突在构造阶段抛错。
- JSON 配置必须为对象，不能传 `null`、数组或字符串。provider、音色和模型字段由服务端校验；客户端透传不代表服务支持这些值。

## TTS 配置：`tts_config`

`tts_config` 与 `asr_config` 同级，在 `init()` 创建 Session 时提交。2.4.1 不提供运行中更新该配置的公开方法。若需要变更会话配置，先销毁旧实例，再使用新配置创建实例。

按平台提供的完整 TTS JSON 配置传入。`emotion` 等音色情感字段是否有效取决于 provider、音色与服务端支持；SDK 不提供通用情感枚举，也不保证语音与面部表情联动。不要用 `speak()` 的第四参数配置 Agent 情感。

<!-- validate:ts -->
```ts
import XingyunAvatarAgent, { type XingyunAvatarAgentOptions } from "@xmov/avatar/agent";

export function createAgent(ttsConfig: NonNullable<XingyunAvatarAgentOptions["tts_config"]>) {
  return new XingyunAvatarAgent({
    containerId: "#agent-avatar",
    appId: "your-app-id",
    appSecret: "your-app-secret",
    gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
    onMessage: console.error,
    tts_config: ttsConfig, // 使用服务端确认的完整配置；生产密钥优先在平台配置
    session_speak_req_id: 0,
  });
}
```

## ASR 配置：`asr_config`

ASR 识别服务的 JSON 配置，具体字段由项目方提供。

#### asr_config 结构

```javascript
{
  "provider": "xmov|doubao|tencent",
  "base_url": "wss://...",
  "headers": { "app_id": "...", "secret_key": "..." },   // doubao: resource_id/access_token/app_id
  "request": { "vad_tail_sil": 600 }
}
```

**初始化接入**

```javascript
const agent = new XingyunAvatarAgent({
  containerId: "",
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  asr_config: {
    provider: "custom-asr",
  },
  onMessage: console.error,
});
```

## Brain 配置：`brain_config`

大模型（Brain）服务的 JSON 配置。

#### **brain_config 结构**

```javascript
{
  // 通用 openai 协议的LLM服务可以使用 openai_compatible
  // anthropic 协议的 使用 anthropic
  "provider": "openai_compatible|anthropic|youling|coze|dify|doubao|qwen|youyan_agent|openai|deepseek",
  "base_url": "...",
  "api_key": "...",
  "model": "...",
  "preset": "...",
  "history_length": 5,
  "extra_body": {}
 }
```

```javascript
const agent = new XingyunAvatarAgent({
  // 省略公共参数
  brain_config: {
    provider: "openai_compatible",
    extra_body: {
      thinking: { type: "disabled" },
    },
  },
  onMessage: console.error,
});
```

### `extra_body`

`brain_config.extra_body` 是可选 JSON 对象：

- SDK **只在调用方显式配置时透传**，不会自动补 `{}`。
- **仅用于 OpenAI-compatible 模型接口**的额外请求参数透传；youling、dify、coze 等应用 API 暂不适配。
- 空对象 `{}` 等同于未配置。

```ts
interface AgentBrainConfig extends Record<string, unknown> {
  extra_body?: Record<string, unknown>; // 仅 OpenAI-compatible 后端下发
}
```

## 功能开关：`features`

### features 参数

| 参数 | 默认值 | 说明 | 适用场景 |
|------|--------|------|---------|
| `speech_frontend.enabled` | 由平台决定 | 语音前端总开关；客户端透传 | 使用平台约定的前端处理能力 |
| `speech_frontend.enable_aec` | 未返回且未请求时客户端回退 `false` | 开启双路音频上行；Session 返回值优先于请求值 | 回声消除，需验证 WebCodecs 音频能力 |
| `speech_frontend.enable_speech_separation` | 由平台决定 | 语音分离；客户端透传 | 按服务端能力启用 |
| `auto_send_asr_to_llm` | `true` | 是否将 ASR 识别结果自动发送给大模型。设置为 `false` 时，ASR 结果不会自动进入大模型处理链路。 | 适合标准语音对话，用户说完后直接触发大模型回复。录音转写、人工确认后提问或需要业务侧审核 ASR 文本时，可以设置为 `false`，收到最终识别结果后再调用 `ask()`。 |
| `anti_interference.semantic_judge_enabled` | `true` | 是否启用抗干扰语义判断。 | 适合展厅、商场、直播、电视声或多人交谈等容易收到无关语音的环境，用于减少背景对话和非目标内容触发大模型。安静环境或不需要语义过滤时可以关闭。 |
| `vad_merge_mode` | `true` | 是否启用 VAD 合并模式。用于控制服务端是否合并被短暂停顿切开的语音片段。 | 适合自然对话、长句输入，以及用户说话时经常思考或停顿的场景，可减少一句话被拆成多次 ASR 结果或多次触发大模型。短口令、固定指令等更关注结束响应速度的场景，可以根据服务端策略关闭。 |
| `volume_and_repetition_text_detection` | `true` | 是否启用音量和重复文本检测。 | 适合远场拾音、用户音量较小、设备回声或相同内容被连续识别的场景，用于辅助发现低音量输入和重复识别问题。录音环境稳定，或业务已经自行处理重复文本时可以关闭。 |

表中非客户端规则的默认值以平台实际配置为准；SDK 不会为缺失字段自动补齐整套服务端默认值。

`features` 用于控制 Agent 的抗干扰与语音检测能力，字段如下：

```ts
interface AgentFeatures {
  speech_frontend?: { enabled?: boolean; enable_aec?: boolean; enable_speech_separation?: boolean };
  anti_interference?: {
    semantic_judge_enabled?: boolean;   // 语义判干扰（防播报被闲聊误触发）
  };
  vad_merge_mode?: boolean;             // 控制服务端是否合并被短暂停顿切开的语音片段。
  volume_and_repetition_text_detection?: boolean; // 音量与重复文本检测
  auto_send_asr_to_llm?: boolean;  // ASR 识别结果直接发送大模型
}
```

```javascript
const agent = new XingyunAvatarAgent({
  // 省略公共参数
  features: {
    anti_interference: {
      semantic_judge_enabled: false,
    },
    vad_merge_mode: true,
    volume_and_repetition_text_detection: false,
  },
});
```
