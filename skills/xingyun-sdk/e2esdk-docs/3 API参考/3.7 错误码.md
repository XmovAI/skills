# 3.7 错误码

`XingyunAvatarAgent` 有两条相互独立的错误通道：

| 通道 | 位置 | 错误结构 | 覆盖范围 |
|------|------|----------|----------|
| `onMessage` | 构造参数顶层 | `SDKError`（数字码） | 具身智能体渲染、会话、解码、网络、WebGL |
| `agentCallbacks.onError` | `agentCallbacks` 内 | `AgentError`（字符串码 + 域） | Agent 初始化、ASR、Brain、网络、配额 |

两者必须同时处理。

## SDKError（经 `onMessage`）

```ts
interface SDKError {
  code: number;      // 错误码
  message: string;   // 错误信息
  timestamp: number; // 时间戳
  originalError?: unknown;
}
```

按码段分级：

| 码段 | 含义 |
|------|------|
| `10001`–`10007` | 初始化错误 |
| `20001`–`20011` | 处理错误 |
| `30001`–`30007` | 资源错误 |
| `40001`–`40007` | 解码错误 |
| `50001`–`50004` | 网络错误 |
| `60001`–`60008` | WebGL / 上下文错误 |

## AgentError（经 `agentCallbacks.onError`）

```ts
interface AgentError {
  code: string;          // 字符串码
  message: string;       // 错误信息
  domain: AgentErrorDomain; // 错误域
  retryable?: boolean;   // 是否可重试
  cause?: unknown;       // 原始原因
}

type AgentErrorDomain = "permission" | "network" | "asr" | "brain" | "ttsa" | "quota" | "sdk";
```

常见错误码：

| 错误码 | 域 | 说明 |
|------|------|------|
| `AGENT_INIT_FAILED` | `sdk` | Agent 初始化失败 |
| `AGENT_ASR_STOP_FAILED` | `asr` | 停止 ASR 失败 |
| `MICROPHONE_ERROR` | `asr` | 麦克风不可用 |
| `MICROPHONE_CLEANUP_FAILED` | `asr` | 释放麦克风资源失败 |
| `MEDIA_RECORDER_ERROR` | `asr` | 录音编码器异常 |
| `AUDIO_WEBM_OPUS_UNSUPPORTED` | `asr` | 浏览器不支持 webm/opus 音频 |
| `AUDIO_WEBCODECS_OPUS_UNSUPPORTED` | `asr` | AEC 路径缺少 WebCodecs Opus 能力 |
| `AUDIO_CHUNK_DURATION_UNSUPPORTED` | `sdk` | AEC 分片时长不是 100ms |
| `AUDIO_CONTEXT_SUSPENDED` | `asr` | AudioContext 未恢复 |
| `AUDIO_ENCODER_ERROR` | `asr` | WebCodecs 编码异常 |
| `E2E_SERVICE_UPDATE_INVALID` | `network` | 服务更新缺少有效迁移凭据 |
| `E2E_MIGRATION_TOKEN_EXPIRED` | `network` | 同房迁移凭据已过期 |
| `E2E_MIGRATION_AUDIO_STOP_FAILED` | `network` | 迁移时音频停止失败 |
| `E2E_MIGRATION_CLOSE_TIMEOUT` | `network` | 旧 E2E 连接未及时关闭 |
| `E2E_MIGRATION_FAILED` | `network` | 同房迁移失败 |
| `E2E_SOCKET_ERROR` | `network` | E2E 控制面连接异常 |
| `E2E_SEND_FAILED` | `network` | E2E 消息发送失败 |
| `E2E_AUDIO_SEND_FAILED` | `network` | E2E 音频上行失败 |
| `E2E_RECONNECTING` | `network` | 正在重连 |
| `E2E_RECONNECT_EXHAUSTED` | `network` | 重连次数耗尽 |
| `E2E_CLOSE_<code>` | `network` | E2E 连接被关闭，`<code>` 为 WebSocket close code |

## WebSocket 关闭码

E2E 控制面 WebSocket 关闭时，`close code` 决定后续行为：

| 关闭码 | 含义 | 处理 |
|------|------|------|
| `4011` | 服务更新迁移 | 使用有效的同房迁移凭据；不走普通新建 Session 兜底 |
| `1001` / `1006` / `1011` / `1012` / `1013` / `1014` | 网络 / 服务异常 | 自动重连 |
| `1000` | 正常关闭 | 用户主动销毁；运行中出现视为终止 |
| `4000` | 路径未知 | 不重连 |
| `4001` | token 无效 | 不重连 |
| `4002` | session 不存在 | 不重连 |
| `4009` | 配额超限 | 不重连 |
| `4010` | 服务端主动断开 | 不重连 |

可恢复关闭码下 SDK 会先短重试，耗尽后重新请求统一会话接口，详见 `2.10 断线重连`。

`retryable` 是错误上下文信息，不等于 SDK 一定自动重连。自动恢复还受关闭码、重连配置和迁移状态影响；服务端错误码可能扩展，保留未知码兜底。
