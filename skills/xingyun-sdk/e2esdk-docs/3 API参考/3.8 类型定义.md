# 3.8 类型定义

本节以 2.4.1 的公开声明为准。下列结构说明不代表每个名字都能从 npm 入口导入。

| 类别 | 使用方式 |
|------|----------|
| `Agent*` 类型（不含文档别名 `AgentServiceConfig`）、`XingyunAvatarAgentOptions` / `Callbacks` / `InitParams` | 从 `@xmov/avatar/agent` 使用 `import type` |
| `RenderState` / `InitModel` / `AvatarStatus` 等渲染类型 | 2.4.1 两个公开入口未导出这些名字；从方法、参数或回调类型推导 |
| `AgentServiceConfig` / `AvatarConfig` | 本页为解释配置使用的辅助类型，不是 SDK 导出；实际 `config` 为 `any` |
| `INetworkInfo` / `FPSStats` / `IRawWidgetData` / `SDKError` 等回调形状 | 从 `XingyunAvatarAgentOptions` 的对应回调推导，避免复制一个不完整 interface |

2.4.1 的 `RenderState` 和 `InitModel` 是字符串枚举，不是可任意赋值的字符串联合。2.5 的导出差异见 [版本基线与差异](<../../references/sdk-versions.md>)。

<!-- validate:ts -->
```ts
import XingyunAvatarAgent, {
  type XingyunAvatarAgentOptions,
  type XingyunAvatarAgentInitParams,
} from "@xmov/avatar/agent";

type RenderState = ReturnType<XingyunAvatarAgent["getRenderState"]>;
type InitModel = NonNullable<XingyunAvatarAgentInitParams["initModel"]>;
type SDKError = Parameters<XingyunAvatarAgentOptions["onMessage"]>[0];
type WidgetEvent = Parameters<NonNullable<XingyunAvatarAgentOptions["onWidgetEvent"]>>[0];

// 2.4.1 未公开导出 InitModel 枚举值；只对已核实的枚举字符串做窄断言。
export async function initInvisible(agent: XingyunAvatarAgent) {
  await agent.init({ initModel: "invisible" as InitModel });
  const renderState: RenderState = agent.getRenderState();
  return renderState;
}
```

## 状态枚举

### `AgentState`

```ts
type AgentState =
  | "idle" | "initializing" | "ready" | "running"
  | "reconnecting" | "stopped" | "destroyed" | "failed";
```

### `AgentSocketState`

```ts
type AgentSocketState = "idle" | "connecting" | "open" | "closed" | "error";
```

### `AgentASRState`

```ts
type AgentASRState =
  | "idle" | "requesting-permission" | "starting" | "listening" | "stopping" | "failed";
```

### `AgentConversationState`

```ts
type AgentConversationState =
  | "idle" | "asking" | "speaking-directly" | "speaking"
```


### `IAvatarOptions`（结构节选，不是 2.4.1 根入口导出）

### 精确回调类型

下面从公开构造参数推导类型，随 SDK 声明更新，避免把完整字段误写成 `{ [key: string]: unknown }`：

<!-- validate:ts -->
```ts
import type { XingyunAvatarAgentOptions } from "@xmov/avatar/agent";
type FPSStats = Parameters<NonNullable<XingyunAvatarAgentOptions["onFPSUpdate"]>>[0];
type IRawWidgetData = Parameters<NonNullable<XingyunAvatarAgentOptions["onWidgetEvent"]>>[0];
type INetworkInfo = Parameters<NonNullable<XingyunAvatarAgentOptions["onNetworkInfo"]>>[0];
```
