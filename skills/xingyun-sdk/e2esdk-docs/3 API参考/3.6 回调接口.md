# 3.6 回调接口

`XingyunAvatarAgent` 的回调分两类：

- **数字人层回调**：挂在构造参数顶层，接收渲染、会话、底层事件与错误（`onMessage`）。
- **Agent 回调**：挂在构造参数 `agentCallbacks` 内，接收状态机、ASR、大模型、网络、配额等事件与错误（`onError`）。

两类回调需同时处理以实现完整的错误与状态覆盖。

## 数字人层回调（构造参数顶层）

### `onMessage(error)`

数字人渲染 / 会话 / 解码 / 网络等底层错误回调，**必须实现**。错误结构见 `3.7 错误码`。

```ts
onMessage: (error: SDKError) => void
```

```javascript
onMessage(error) {
  console.error("数字人错误", error.code, error.message);
}
```

### `onStatusChange(status)`

数字人连接状态变化（`AvatarStatus`：`online=0 | offline=1 | close=4 | visible=5 | invisible=6`）。

```ts
onStatusChange: (status: AvatarStatus) => void
```

### `onRenderChange(state)`

渲染状态变化（`RenderState`：`init | rendering | pausing | paused | resumed | stopped`）。

```ts
onRenderChange: (state: RenderState) => void
```

### `onVoiceStateChange(state, duration?, client_speak_id?)`

语音状态与耗时变化。

```ts
onVoiceStateChange: (state: string, duration?: number, client_speak_id?: string | number) => void
```

### `onSpeakStateChange(state, client_speak_id)`

数字人播报状态变化。

```ts
onSpeakStateChange: (state: string, client_speak_id: string | number) => void
```

### `onWalkStateChange(state)`

行走状态变化。

```ts
onWalkStateChange: (state: string) => void
```

### `onWidgetEvent(data)`

内置 Widget 事件回调（字幕、图片等），`data` 为 `IRawWidgetData`。

```ts
onWidgetEvent: (data: IRawWidgetData) => void
```

### `proxyWidget`

自定义 Widget 事件分发表，键为事件类型，值为处理函数。见 `2.9 UI 组件（Widget）`。

```ts
proxyWidget: { [type: string]: (data: any) => void }
```

### `onNetworkInfo(info)`

网络指标回调。

```ts
onNetworkInfo: (info: INetworkInfo) => void
```

### `onStartSessionWarning(message)`

会话告警回调。

```ts
onStartSessionWarning: (message: object) => void
```

### `onFPSUpdate(stats)`

帧率统计回调。

```ts
onFPSUpdate: (stats: FPSStats) => void
```

## Agent 回调（agentCallbacks 内）

### `onAgentStateChange(state)`

Agent 整体生命周期状态变化（`AgentState`），是驱动页面加载态 / 可用态的主要信号。

```ts
onAgentStateChange: (state: AgentState) => void
```

### `onSocketStateChange(state)`

E2E 控制面 WebSocket 状态变化（`AgentSocketState`：`idle | connecting | open | closed | error`）。

```ts
onSocketStateChange: (state: AgentSocketState) => void
```

### `onASRStateChange(state)`

ASR / 麦克风状态变化（`AgentASRState`）。

```ts
onASRStateChange: (state: AgentASRState) => void
```

### `onASRResult(result)`

ASR 识别文本回调。本轮识别会先产出多条 `isFinal: false` 的中间结果，最终一条 `isFinal: true`。

```ts
onASRResult: (result: AgentASRResult) => void
// result: { text: string; isFinal: boolean; raw?: unknown }
```

```javascript
onASRResult(result) {
  subtitle.textContent = result.text;
  if (result.isFinal) recordingIndicator.hidden = true;
}
```

### `onLLMResponse(response)`

大模型回复流式回调。`event: "chunk"` 为分片文本，可拼接展示；`event: "done"` 表示本轮回复结束，含 `usage` 用量统计。

```ts
onLLMResponse: (response: AgentLLMResponse) => void
// response:
//   { event: "chunk"; text?: string; isFirst?: boolean; raw?: unknown }
// | { event: "done"; text?: string; usage?: AgentLLMUsage; raw?: unknown }
```

### `onSpeakStateChange(event)`

数字人播报状态变化（**注意**：与顶层同名回调签名不同，此处参数为对象）。`event.state` 复用 TTSA 播报状态，取值与顶层 `onSpeakStateChange` 相同：`speak_start` / `speak_end` / `speak_error`。

```ts
onSpeakStateChange: (event: AgentSpeakStateEvent) => void
// event: { state: string; clientSpeakId?: string | number; raw?: unknown }
```

### `onConversationChange(event)`

对话业务状态变化（`AgentConversationState`：`idle | asking | speaking | completed | failed`），是判断一轮对话完成的主要信号。

```ts
onConversationChange: (event: AgentConversationEvent) => void
// event: { state: AgentConversationState; text?: string; raw?: unknown }
```

### `onSemanticJudgeResult(result)`

抗干扰语义判断结果，仅在启用语义判干扰时触发。

```ts
onSemanticJudgeResult: (result: AgentSemanticJudgeResult) => void
// result: { query: string; meaningful: boolean; action: string; raw?: unknown }
```

### `onRenderChange(state)` / `onNetworkInfo(info)`

渲染状态 / 网络指标透传回调，与顶层同名回调一致。

### `onError(error)`

Agent / ASR / Brain / 网络 / 配额等错误回调。`error` 为 `AgentError`，结构见 `3.7 错误码`。

```ts
onError: (error: AgentError) => void
```

```javascript
onError(error) {
  if (error.retryable) {
    toast(`出了点问题，可稍后重试（${error.code}）`);
  } else {
    toast(`服务不可用：${error.message}`);
  }
}
```

## 回调使用约定

- 回调内**不要抛出异常**，也不要做耗时的同步计算。
- 回调内若需异步操作，自行 `catch`，避免 Promise 拒绝未被处理。
- 深度依赖状态时，优先在回调内取用 `getAgentState()` / `getASRState()` 的当前值。
