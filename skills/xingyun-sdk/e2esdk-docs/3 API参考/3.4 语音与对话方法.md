# 3.4 语音与对话方法

本节说明 `XingyunAvatarAgent` 的对话与语音识别相关方法。

## 方法：`ask()`

发起一次 Brain（大模型）对话：文本送入 Brain，回复经数字人播报。返回仅表示请求已写入，**不代表本轮播报已经结束**，需通过 `onSpeakStateChange` 或 `onConversationChange` 判断完成。

**签名**

```ts
ask(text: string): Promise<void>
```

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | `string` | 是 | 发送给 Brain 的文本 |

**示例**

```javascript
agent.ask("介绍一下这个产品");
```

## 方法：`startASR()`

申请麦克风权限并开始语音识别。识别文本通过 `agentCallbacks.onASRResult` 回调，识别完成后自动进入 Brain 对话链路。应在用户手势（如按钮点击）中调用以满足浏览器权限策略。

**签名**

```ts
startASR(): Promise<void>
```

**示例**

```javascript
startButton.addEventListener("click", async () => {
  try {
    await agent.startASR();
  } catch (error) {
    console.error("ASR 启动失败", error);
  }
});
```

## 方法：`stopASR()`

结束本轮识别并释放麦克风资源。

**签名**

```ts
stopASR(): Promise<void>
```

**示例**

```javascript
agent.stopASR();
```

## 方法：`speak()`

让数字人按 SSML 播报文本。SSML 标签说明见 `2.5 数字人播报与 SSML`。

**签名**

```ts
speak(ssml: string, is_start?: boolean, is_end?: boolean, extra?: object): string | undefined
```

**参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `ssml` | `string` | 是 | — | SSML 播报内容 |
| `is_start` | `boolean` | 否 | — | 标识是否为分段播报的首段 |
| `is_end` | `boolean` | 否 | — | 标识是否为分段播报的末段 |
| `extra` | `object` | 否 | — | 附加参数，如 `{ emotion: "..." }`，见 `2.8` |

**返回值**：`string | undefined`，本次播报的请求 ID。

**示例**

```javascript
agent.speak('你好，欢迎体验数字人');
```

## 方法：`interrupt()`

客户端打断当前数字人播报。

**签名**

```ts
interrupt(type: string): number
```

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | `string` | 是 | 打断类型标识，由业务自定义 |

**返回值**：`number`，打断耗时（毫秒）。

打断不会关闭麦克风或 ASR；需要结束监听时再调用 `stopASR()`。打断同时受构造参数 `enableClientInterrupt` 控制（默认 `true`）。

**示例**

```javascript
interruptButton.addEventListener("click", () => {
  agent.interrupt("user_click");
});
```
