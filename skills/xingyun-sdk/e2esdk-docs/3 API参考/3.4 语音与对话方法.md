# 3.4 语音与对话方法

本节说明 `XingyunAvatarAgent` 的对话与语音识别相关方法。

## 方法：`ask()`

发起一次 Brain（大模型）对话：文本送入 Brain，回复经具身智能体播报。返回仅表示请求已写入，**不代表本轮播报已经结束**，需通过 `onSpeakStateChange` 或 `onConversationChange` 判断完成。

**签名**

```ts
ask(text: string): Promise<void>
```

**参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | `string` | 是 | 发送给 Brain 的文本 |

**示例**

```javascript
agent.ask("介绍一下这个产品");
```

## 方法：`startASR()`

申请麦克风权限并开始语音识别。识别文本通过 `agentCallbacks.onASRResult` 回调，识别完成后是否进入 Brain 由 `features.auto_send_asr_to_llm` 决定。应在用户手势（如按钮点击）中调用以满足浏览器权限策略。

**签名**

```ts
startASR(options?: AgentASRStartOptions): Promise<void>
```

`options.inputStream` 可传入业务持有的外部音频流，SDK 克隆其中一条有效音轨。`stopASR()` / `destroy()` 不负责停止原流，详见 [外部音频流与 AEC](<../2 功能介绍/2.4 语音识别与麦克风.md>)。

**示例**

```javascript
startButton.addEventListener("click", async () => {
  try {
    await agent.startASR();
  } catch (error) {
    console.error("ASR 启动失败", error);
  }
});
```

## 方法：`stopASR()`

结束本轮识别并释放麦克风资源。

**签名**

```ts
stopASR(): Promise<void>
```

**示例**

```javascript
agent.stopASR();
```

## 方法：`speak()`

让具身智能体按 SSML 播报文本。SSML 标签说明见 `2.5 具身智能体播报与 SSML`。

**签名**

```ts
speak(ssml: string, is_start?: boolean, is_end?: boolean): string | undefined
```

**参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `ssml` | `string` | 是 | — | SSML 播报内容 |
| `is_start` | `boolean` | 否 | `true` | 标识是否为分段播报的首段 |
| `is_end` | `boolean` | 否 | `true` | 标识是否为分段播报的末段 |

**返回值**：声明保留 `string | undefined`；常规 Agent 播报返回 `undefined`，不能用返回值关联播报 ID 或等待完成。通过构造参数中的 `onSpeakStateChange` 或 `agentCallbacks.onConversationChange` 监听完成。Agent 不接受第四参数 `extra`，单次 `extra.emotion` 不属于此入口的公开契约。

**示例**

```javascript
agent.speak('你好，欢迎体验具身智能体');
```

## 方法：`interrupt()`

客户端打断当前具身智能体播报。

**签名**

```ts
interrupt(): number
```

**参数**：无。业务日志中的打断原因由调用方自行记录。

**返回值**：`number`，打断耗时（毫秒）。

打断不会关闭麦克风或 ASR；需要结束监听时再调用 `stopASR()`。显式调用 `interrupt()` 会发送 E2E 打断并执行本地清理；`enableClientInterrupt: false` 不能当作禁止显式打断的开关。

**示例**

```javascript
interruptButton.addEventListener("click", () => {
  agent.interrupt();
});
```
