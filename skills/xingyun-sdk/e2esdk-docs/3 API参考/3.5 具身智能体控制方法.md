# 3.5 具身智能体控制方法

本节说明 `XingyunAvatarAgent` 对具身智能体播放与外观的控制方法。

## 方法：`idle()`

让具身智能体进入待机状态（默认姿态）。

**签名**

```ts
idle(): void
```

## 方法：`listen()`

让具身智能体进入聆听状态（如对话中等待用户说话）。

**签名**

```ts
listen(): void
```

## 方法：`interactiveidle()`

让具身智能体进入交互待机状态（区别于普通待机的姿态）。

**签名**

```ts
interactiveidle(): void
```

## 方法：`changeLayout()`

动态调整具身智能体布局，如位置、缩放、朝向。

**签名**

```ts
changeLayout(layout: Layout): void
```

`Layout` 字段见 `3.8 类型定义`（`scale` 支持数字倍率或 `vh` 单位），示例见 `2.7 布局与隐身`。

## 方法：`changeWalkConfig()`

动态调整具身智能体行走配置。

**签名**

```ts
changeWalkConfig(walkConfig: WalkConfig): void
```

示例见 `2.8 动作、行走与表情`。

## 方法：`changeAvatarVisible()`

切换具身智能体可见 / 不可见。

**签名**

```ts
changeAvatarVisible(visible: boolean): void
```

**示例**

```javascript
agent.changeAvatarVisible(false); // 隐藏
agent.changeAvatarVisible(true);  // 显示
```

## 方法：`switchInvisibleMode()`

切换隐身模式（具身智能体隐藏但保持会话），用于页面切后台 / 多开场景。可用 `onStatusChange` 状态 `visible=5` / `invisible=6` 感知结果。

**签名**

```ts
switchInvisibleMode(): void
```

详见 `2.7 布局与隐身`。

## 方法：`setVolume()`

设置具身智能体音量。

**签名**

```ts
setVolume(volume: number): void
```

**参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| `volume` | `number` | 音量，取值 0.0–1.0 |

**示例**

```javascript
agent.setVolume(0.5);
```

## 方法：`showDebugInfo()` / `hideDebugInfo()`

显示 / 隐藏调试信息面板（需构造参数 `enableDebugger: true`）。

**签名**

```ts
showDebugInfo(): void
hideDebugInfo(): void
```

## 方法：`offlineMode()` / `onlineMode()`

切换具身智能体渲染数据通道的模式。`offlineMode()` 进入离线渲染，`onlineMode()` 回到在线渲染。

**签名**

```ts
offlineMode(): void
onlineMode(): void
```

## 方法：`reStartSession()`

重新建立具身智能体渲染会话。

**签名**

```ts
reStartSession(): void
```
