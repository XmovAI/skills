# 3.1 构造参数

本节说明创建 `XingyunAvatarAgent` 实例时的构造参数。

```ts
new XingyunAvatarAgent(options: XingyunAvatarAgentOptions)
```

构造参数分四组：**必填**、**容器（二选一）**、**具身智能体渲染**、**Agent 服务与连接**。除必填项外均为可选。

## 必填参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `appId` | `string` | 应用 ID，由项目方分配 |
| `appSecret` | `string` | 与 `appId` 配套的浏览器侧签名凭证 |
| `gatewayServer` | `string` | 统一会话接口地址，公共网关为`https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session`。私有化部署则需要专门指定 |
| `onMessage` | `(error: SDKError) => void` | 具身智能体渲染、会话、底层错误回调，必须实现 |

## 容器参数（二选一）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `containerId` | `string` | 条件必填 | 容器 CSS 选择器，如 `#agent-avatar` |
| `container` | `HTMLElement` | 条件必填 | 容器 DOM 元素，与 `containerId` 二选一，同时提供时优先级更高 |

具身智能体渲染需要一个**有明确宽高**的 DOM 容器，否则画布可能折叠为零尺寸。

## 具身智能体渲染参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `config` | `AvatarConfig` | 无 | 具身智能体运行时配置（布局、行走、背景、音频、初始事件等），见 `3.8 类型定义` |
| `enableClientInterrupt` | `boolean` | `true` | 是否启用客户端打断 |
| `enableDebugger` | `boolean` | `false` | 是否启用调试模式，配合 `showDebugInfo()` 使用 |

## Agent 服务配置参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `asr_config` | `Record<string, unknown>` | 无 | ASR 服务 JSON 配置，空对象 `{}` 不发送 |
| `features` | `AgentFeatures` | 无 | Agent 功能配置，空对象 `{}` 不发送 |
| `brain_config` | `AgentBrainConfig` | 无 | Brain 服务 JSON 配置，空对象 `{}` 不发送 |

各 JSON 配置为透传，将原样发送到统一会话接口，字段结构详见 `2.2 服务与大脑配置`。

## Agent 连接与音频参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `e2eServer` | `string` | 无 | 私有化 / 调试用 E2E 地址兜底，须与 `authToken` 成对使用 |
| `authToken` | `string` | 无 | 私有化 / 调试用 E2E token，须与 `e2eServer` 成对使用 |
| `audio` | `AgentAudioOptions` | 见类型定义 | 音频输入 / 分片配置 |
| `reconnect` | `AgentReconnectOptions` | 开启 | 断线重连配置 |
| `agentCallbacks` | `XingyunAvatarAgentCallbacks` | 无 | Agent 状态、识别、对话、错误回调，见 `3.6 回调接口` |
| `webSocketCtor` | `typeof WebSocket` | `globalThis.WebSocket` | 仅供测试注入，业务代码不要配置 |

## 具身智能体回调（顶层，均可选）

以下回调挂载在构造参数顶层，用于接收具身智能体渲染层事件，详见 `3.6 回调接口`：

| 回调 | 签名 | 说明 |
|------|------|------|
| `onStatusChange` | `(status: AvatarStatus) => void` | 具身智能体连接状态变化 |
| `onRenderChange` | `(state: RenderState) => void` | 渲染状态变化 |
| `onVoiceStateChange` | `(state, duration?, client_speak_id?) => void` | 语音状态变化（含耗时、client_speak_id） |
| `onSpeakStateChange` | `(state, client_speak_id) => void` | 播报状态变化 |
| `onWalkStateChange` | `(state) => void` | 行走状态变化 |
| `onWidgetEvent` | `(data: IRawWidgetData) => void` | 内置 Widget 事件 |
| `proxyWidget` | `{ [type]: (data) => void }` | 自定义 Widget 事件分发 |
| `onNetworkInfo` | `(info: INetworkInfo) => void` | 网络指标回调 |
| `onStartSessionWarning` | `(message: object) => void` | 会话告警回调 |
| `onFPSUpdate` | `(stats: FPSStats) => void` | 帧率统计回调 |

## 最小示例

```javascript
import XingyunAvatarAgent from "@xmov/avatar/agent";

const agent = new XingyunAvatarAgent({
  container: document.getElementById("agent-avatar"),
  appId: "your-app-id",
  appSecret: "your-app-secret",
  gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
  asr_config: { provider: "your-asr-provider" },
  brain_config: { provider: "your-brain-provider" },
  onMessage(error) {
    console.error("渲染错误", error);
  },
  agentCallbacks: {
    onError(error) {
      console.error("Agent 错误", error.code, error.message);
    },
  },
});

agent.init();
```
