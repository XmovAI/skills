# 3.3 会话与状态方法

本节说明 `XingyunAvatarAgent` 的状态查询方法。它们均为同步方法，可用于驱动页面 UI（按钮禁用、加载态、字幕等）。

## 方法：`getAgentState()`

返回 Agent 整体生命周期状态。

**签名**

```ts
getAgentState(): AgentState
```

`AgentState` 取值：`idle | initializing | ready | running | reconnecting | stopped | destroyed | failed`，含义见下表：

| 状态 | 含义 |
|------|------|
| `idle` | 已构造，尚未初始化 |
| `initializing` | 正在初始化 |
| `ready` | 会话就绪，等待进入 running |
| `running` | 运行中，可对话 / 识别 |
| `reconnecting` | 断线重连中 |
| `stopped` | 已停止 |
| `destroyed` | 已销毁 |
| `failed` | 失败 |

**示例**

```javascript
if (agent.getAgentState() === "running") {
  askButton.disabled = false;
}
```

## 方法：`getASRState()`

返回语音识别 / 麦克风状态。

**签名**

```ts
getASRState(): AgentASRState
```

`AgentASRState` 取值：`idle | requesting-permission | starting | listening | stopping | failed`。

**示例**

```javascript
agentCallbacks.onASRStateChange = (state) => {
  micButton.classList.toggle("active", state === "listening");
};
```

## 方法：`getStatus()`

返回数字人渲染层的连接状态。

**签名**

```ts
getStatus(): AvatarStatus
```

`AvatarStatus` 为数值枚举：`online=0 | offline=1 | close=4 | visible=5 | invisible=6`。

## 方法：`getRenderState()`

返回数字人渲染状态。

**签名**

```ts
getRenderState(): RenderState
```

`RenderState` 取值：`init | rendering | pausing | paused | resumed | stopped`。

## 方法：`getSessionId()`

返回当前会话 ID；未建会话时返回 `undefined`。

**签名**

```ts
getSessionId(): string | undefined
```

## 方法：`isDestroyed()`

返回实例是否已销毁。

**签名**

```ts
isDestroyed(): boolean
```

## 方法：`getOptions()`

返回实例当前生效的构造参数。

**签名**

```ts
getOptions(): IAvatarOptions
```
