# 1.3 安装与集成

本页以 `@xmov/avatar@2.4.1` 为基准。2.5 开发版的公开接口变化见 [版本基线与差异](<../../references/sdk-versions.md>)。

## 安装

```bash
npm install --save-exact @xmov/avatar@2.4.1
# 或
pnpm add --save-exact @xmov/avatar@2.4.1
# 或
yarn add --exact @xmov/avatar@2.4.1
```

## ESM 引入

在 Vite、Webpack 等构建工具中使用包入口：

```ts
import XingyunAvatarAgent from "@xmov/avatar/agent";
```

浏览器原生 HTML 无法直接解析 `@xmov/avatar/agent` 这个包名，应使用下方 CDN 示例，或先通过构建工具打包。SDK 依赖浏览器环境；SSR 项目应在客户端加载模块并创建实例，不在服务端执行 SDK。

## CDN 引入与原生 JS 示例

自包含 E2E 构建提供全局构造器 `window.XingyunAvatarAgent`，无需另外加载旧版 SDK。以下地址固定为 2.4.1；`@latest` 是浮动标签，不作为版本基线。

<!-- validate:html -->
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>具身智能体集成</title>
</head>
<body>
  <div id="agent-avatar" style="width: 360px; height: 640px;"></div>
  <button id="connect">连接</button>
  <p id="status" role="status">未连接</p>
  <script src="https://media.xingyun3d.com/xingyun3d/general/litesdk/xmovAvatar_e2e.2.4.1.js"></script>
  <script>
    let agent;
    const button = document.getElementById("connect");
    const status = document.getElementById("status");
    button.addEventListener("click", async () => {
      button.disabled = true;
      try {
        agent = new window.XingyunAvatarAgent({
          containerId: "#agent-avatar",
          appId: "your-app-id",
          appSecret: "your-app-secret",
          gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
          onMessage: console.error,
          agentCallbacks: { onError: console.error },
        });
        await agent.init();
        status.textContent = "已就绪";
      } catch (error) {
        console.error(error);
        status.textContent = "初始化失败，请检查配置后重试";
        await agent?.destroy("init_failed").catch(console.error);
        agent = undefined;
        button.disabled = false;
      }
    });
    window.addEventListener("pagehide", () => {
      void agent?.destroy("page_hide").catch(console.error);
    });
  </script>
</body>
</html>
```

容器必须有明确宽高。页面退出的网络请求可能被浏览器终止；`destroy()` 是清理入口，服务端房间释放仍需结合网关日志验证。

## Vue 3

在 `onMounted` 后读取 DOM。SDK 实例使用普通变量，避免被深度响应式代理；`onBeforeUnmount` 发起销毁并处理 Promise 拒绝。Vue 不会等待异步卸载清理。

<!-- validate:vue -->
```vue
<script setup lang="ts">
import { ref, onMounted, onBeforeUnmount } from "vue";
import XingyunAvatarAgent from "@xmov/avatar/agent";

const container = ref<HTMLDivElement | null>(null);
let agent: XingyunAvatarAgent | undefined;

onMounted(() => {
  const element = container.value;
  if (!element) return;
  try {
    const instance = new XingyunAvatarAgent({
      containerId: "", // 2.4.1 的类型仍要求此字段；运行时优先使用 container
      container: element,
      appId: "your-app-id",
      appSecret: "your-app-secret",
      gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
      onMessage: console.error,
      agentCallbacks: { onError: console.error },
    });
    agent = instance;
    void instance.init().catch(async (error: unknown) => {
      console.error("初始化失败或已取消", error);
      await instance.destroy("init_failed").catch(console.error);
      if (agent === instance) agent = undefined;
    });
  } catch (error) {
    console.error("创建实例失败", error);
  }
});

onBeforeUnmount(() => {
  const instance = agent;
  agent = undefined;
  void instance?.destroy("component_unmount").catch(console.error);
});
</script>

<template>
  <div ref="container" style="width: 360px; height: 640px;"></div>
</template>
```

参见 [Vue 生命周期](https://vuejs.org/api/composition-api-lifecycle.html)。如果浏览器要求用户手势才能启用音频，可把创建与初始化移到按钮处理函数，保留 DOM 存在性检查和卸载清理。

## React

每次 effect 持有自己的实例。开发环境 Strict Mode 会执行额外的 setup / cleanup 周期；清理旧实例时，不应通过共享 ref 销毁新一轮 effect 的实例。

<!-- validate:tsx -->
```tsx
import { useEffect, useRef } from "react";
import XingyunAvatarAgent from "@xmov/avatar/agent";

export default function AvatarComponent() {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const element = containerRef.current;
    if (!element) return;
    let instance: XingyunAvatarAgent;
    try {
      instance = new XingyunAvatarAgent({
        containerId: "",
        container: element,
        appId: "your-app-id",
        appSecret: "your-app-secret",
        gatewayServer: "https://nebula-agent.xingyun3d.com/user/v1/ttsa_v2/session",
        onMessage: console.error,
        agentCallbacks: { onError: console.error },
      });
    } catch (error) {
      console.error("创建实例失败", error);
      return;
    }
    void instance.init().catch(async (error: unknown) => {
      console.error("初始化失败或已取消", error);
      await instance.destroy("init_failed").catch(console.error);
    });
    return () => {
      void instance.destroy("component_unmount").catch(console.error);
    };
  }, []);

  return <div ref={containerRef} style={{ width: 360, height: 640 }} />;
}
```

同一实例的 `destroy()` 可重复调用；不应以“只执行一次”的全局标记跳过后续 effect 的清理。参见 [React useEffect](https://react.dev/reference/react/useEffect)。路由快速切换、Strict Mode、初始化期间卸载和真实麦克风释放仍需在目标浏览器验收。
