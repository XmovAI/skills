# OpenCode Installation Instructions for Xingyun Skills

To install and use Xingyun SDK skills in OpenCode:

1. Copy or link `skills/xingyun-sdk` into your project's `.opencode/skills/` directory:
   ```bash
   mkdir -p .opencode/skills
   cp -r skills/xingyun-sdk .opencode/skills/
   ```

2. OpenCode will automatically load the skill definition from `skills/xingyun-sdk/SKILL.md`.
